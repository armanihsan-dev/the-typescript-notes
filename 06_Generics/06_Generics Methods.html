GENERIC METHODS

COMPLETE NOTES ON BUILDING TYPE-SAFE METHODS IN OBJECTS

🎯 What Are Generic Methods?

Definition:

A generic method is a method (a function inside an object) that declares its own type parameters (<T>). It can work with any type while preserving type safety.

const objectName = {
    methodName(param: T): T {
        return param;
    }
};
  • <T> is declared on the method
  • T is used for parameter types and/or return type
  • Each call can have a different type

🧠 How It Works

const utils = {
    identity(value: T): T {
        return value;
    }
};

const a = utils.identity("hello"); // T = string
const b = utils.identity(42);      // T = number
const c = utils.identity(true);    // T = boolean

What Happens:

  • T is a placeholder for any type
  • TypeScript infers T from the argument
  • The return type is exactly the same type
  • The variable storing the result gets that type

✅ Basic Syntax

const myObject = {
    // Single generic type
    methodName(param: T): T {
        return param;
    },

    // Multiple generic types
    pair(first: T, second: U): [T, U] {
        return [first, second];
    },

    // With constraint
    getLength(item: T): number {
        return item.length;
    },

    // Arrow function syntax
    wrap: (value: T): T[] => [value]
};

📦 Examples

1. Identity — Same Type In, Same Type Out

const utils = {
    identity(value: T): T {
        return value;
    }
};

const result = utils.identity("hello");
// result: string

2. Pair — Two Different Types

const utils = {
    pair(first: T, second: U): [T, U] {
        return [first, second];
    }
};

const result = utils.pair("hello", 42);
// result: [string, number]

3. Length — With Constraint

const utils = {
    getLength(item: T): number {
        return item.length;
    }
};

const a = utils.getLength("hello");   // 5
const b = utils.getLength([1, 2, 3]); // 3
// utils.getLength(42);              // ❌ Error: number has no length

4. Array Wrapper

const utils = {
    wrapInArray: (value: T): T[] => [value]
};

const result = utils.wrapInArray(42);
// result: number[]

5. First Element of Array

const utils = {
    first(items: T[]): T | undefined {
        return items[0];
    }
};

const result = utils.first([1, 2, 3]);
// result: number | undefined

🔁 Return Type = Variable Type

const transformer = {
    toString(value: T): string {
        return String(value);
    },

    logAndReturn(value: T): T {
        console.log(value);
        return value;
    }
};

// ──────────────────────────────────────────

const a = transformer.toString(42);
// a: string

const b = transformer.logAndReturn("hello");
// b: string

const c = transformer.logAndReturn(100);
// c: number

const d = transformer.logAndReturn({ name: "Alice" });
// d: { name: string }

📦 Real‑World Example: API Client

const apiClient = {
    get(url: string): Promise {
        return fetch(url).then(res => res.json());
    },

    post(url: string, body: U): Promise {
        return fetch(url, {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify(body)
        }).then(res => res.json());
    }
};

// Usage:
interface User {
    id: number;
    name: string;
}

const user = await apiClient.get("/users/1");
// user: User

const newUser = await apiClient.post(
    "/users",
    { name: "Alice" }
);
// newUser: User

📦 JSON Helper (Practical)

const jsonHelper = {
    stringify(data: T): string {
        return JSON.stringify(data);
    },

    parse(json: string): T {
        return JSON.parse(json) as T;
    }
};

// Usage:
const user = { id: 1, name: "Alice" };
const json = jsonHelper.stringify(user);   // string
const parsed = jsonHelper.parse(json); // User

✅ Key Takeaway

A generic method inside an object:

  • Declares its own <T>
  • Infers T from the argument
  • Returns the exact type you need
  • The variable storing the result gets that type
