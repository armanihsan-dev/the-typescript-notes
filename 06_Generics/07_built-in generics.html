A COMPLETE GUIDE TO MAP, SET, READONLY, AND READONLYARRAY

🎯 What You'll Learn

Map<K, V> Key-value pair collection with custom typed keys & values

Part 1: Map<K, V> — Key-Value Collection

Definition

Map<K, V> is a collection of key-value pairs where keys and values can be of any type. Keys are guaranteed to be unique.

Syntax

const map = new Map<K, V>();

How It Works

// ✅ Create a Map with string keys and number values
const scores = new Map<string, number>();

// Add values
scores.set("Alice", 100);
scores.set("Bob", 90);
scores.set("Charlie", 85);

// Get values
console.log(scores.get("Alice")); // 100
console.log(scores.get("Bob"));   // 90

// Check if key exists
console.log(scores.has("Alice")); // true
console.log(scores.has("David")); // false

// Delete a key
scores.delete("Charlie");

// Get size
console.log(scores.size); // 2

// Iterate
for (const [key, value] of scores) {
    console.log(`${key}: ${value}`);
}
// Output:
// Alice: 100
// Bob: 90

Different Key Types

// ✅ Number keys
const userMap = new Map<number, string>();
userMap.set(1, "Alice");
userMap.set(2, "Bob");

// ✅ Object keys
const objKey = { id: 1 };
const objectMap = new Map<object, string>();
objectMap.set(objKey, "Value for object key");

// ✅ Mixed keys
const mixedMap = new Map<string | number, string>();
mixedMap.set("name", "Alice");
mixedMap.set(42, "The answer");

Real-World Example: User Cache

interface User {
    id: number;
    name: string;
    email: string;
}

class UserCache {
    private cache = new Map<number, User>();

    set(user: User): void {
        this.cache.set(user.id, user);
    }

    get(id: number): User | undefined {
        return this.cache.get(id);
    }

    has(id: number): boolean {
        return this.cache.has(id);
    }

    delete(id: number): boolean {
        return this.cache.delete(id);
    }

    clear(): void {
        this.cache.clear();
    }

    getAll(): User[] {
        return Array.from(this.cache.values());
    }
}

// Usage
const cache = new UserCache();
cache.set({ id: 1, name: "Alice", email: "alice@email.com" });
cache.set({ id: 2, name: "Bob", email: "bob@email.com" });

const user = cache.get(1);
console.log(user?.name); // "Alice"

Map Methods Summary

Method What It Does
set(key, value) Adds a key-value pair
get(key) Gets value for a key
has(key) Checks if key exists
delete(key) Removes key-value pair
clear() Removes all entries
size Returns number of entries
keys() Returns iterator of keys
values() Returns iterator of values
entries() Returns iterator of [key, value]
forEach(callback) Iterates over entries

Part 2: Set<T> — Unique Values Collection

Definition

Set<T> is a collection of unique values of type T. Duplicate entries are automatically ignored.

Syntax

const set = new Set<T>();

How It Works

// ✅ Create a Set of strings
const names = new Set<string>();

// Add values
names.add("Alice");
names.add("Bob");
names.add("Charlie");
names.add("Alice"); // ❌ Duplicate! Ignored.

console.log(names.size); // 3

// Check if value exists
console.log(names.has("Alice")); // true
console.log(names.has("David")); // false

// Delete a value
names.delete("Charlie");

// Iterate
for (const name of names) {
    console.log(name);
}
// Output:
// Alice
// Bob

Different Value Types

// ✅ Number Set
const numbers = new Set<number>();
numbers.add(1);
numbers.add(2);
numbers.add(3);
numbers.add(1); // ❌ Duplicate! Ignored.

// ✅ Mixed types
const mixed = new Set<string | number>();
mixed.add("hello");
mixed.add(42);
// mixed.add(true); // ❌ Error: boolean not assignable to string | number

// ✅ Object Set (objects are compared by reference)
const obj1 = { id: 1 };
const obj2 = { id: 1 };
const objectSet = new Set<object>();
objectSet.add(obj1);
objectSet.add(obj2); // ✅ Both added (distinct memory references)
console.log(objectSet.size); // 2

// ❌ Same object reference
const sameObj = { id: 1 };
objectSet.add(sameObj);
objectSet.add(sameObj); // ❌ Duplicate! Ignored.
console.log(objectSet.size); // 3 (obj1, obj2, sameObj)

Real-World Example: Unique Tags

class TagManager {
    private tags = new Set<string>();

    addTag(tag: string): void {
        this.tags.add(tag);
    }

    addTags(tags: string[]): void {
        tags.forEach(tag => this.tags.add(tag));
    }

    hasTag(tag: string): boolean {
        return this.tags.has(tag);
    }

    removeTag(tag: string): boolean {
        return this.tags.delete(tag);
    }

    getAllTags(): string[] {
        return Array.from(this.tags);
    }

    getTagCount(): number {
        return this.tags.size;
    }

    clear(): void {
        this.tags.clear();
    }
}

// Usage
const tags = new TagManager();
tags.addTags(["javascript", "typescript", "react", "typescript"]);
console.log(tags.getAllTags()); // ["javascript", "typescript", "react"]
console.log(tags.getTagCount()); // 3

Set Methods Summary

Method What It Does
add(value) Adds a value (duplicates ignored)
has(value) Checks if value exists
delete(value) Removes a value
clear() Removes all values
size Returns number of values
keys() Returns iterator of values
values() Returns iterator of values
entries() Returns iterator of [value, value]
forEach(callback) Iterates over values

Part 3: Readonly<T> — Immutable Object Type

Definition

Readonly<T> is a built-in utility type that makes all properties of T read-only. Reassignment to top-level properties will trigger compile-time errors.

Syntax

type Readonly<T> = {
    readonly [P in keyof T]: T[P];
};

How It Works

interface User {
    id: number;
    name: string;
    email: string;
}

// ❌ Mutable
const user: User = { id: 1, name: "Alice", email: "a@b.com" };
user.name = "Bob"; // ✅ Allowed

// ✅ Readonly
const readonlyUser: Readonly<User> = { id: 1, name: "Alice", email: "a@b.com" };
// readonlyUser.name = "Bob"; // ❌ Error: Cannot assign to 'name' because it is a read-only property
// readonlyUser.id = 2;       // ❌ Error: Cannot assign to 'id' because it is a read-only property

Deep Readonly (Nested Caution)

// ❌ Readonly is SHALLOW (only top level)
interface User {
    id: number;
    address: {
        street: string;
        city: string;
    };
}

const user: Readonly<User> = {
    id: 1,
    address: {
        street: "123 Main St",
        city: "NYC"
    }
};

// user.id = 2;                     // ❌ Error: readonly
user.address.street = "456 Oak St"; // ✅ Allowed! (nested properties are NOT readonly)

Deep Readonly Helper

// ✅ DeepReadonly: Recursively makes ALL nested properties readonly
type DeepReadonly<T> = {
    readonly [P in keyof T]: T[P] extends object
        ? DeepReadonly<T[P]>
        : T[P];
};

interface User {
    id: number;
    address: {
        street: string;
        city: string;
    };
}

const deepUser: DeepReadonly<User> = {
    id: 1,
    address: {
        street: "123 Main St",
        city: "NYC"
    }
};

// deepUser.id = 2;                       // ❌ Error: readonly
// deepUser.address.street = "456 Oak St"; // ❌ Error: readonly (deep!)

When to Use Readonly<T>

Use Case Example
Constants const config: Readonly<AppConfig>
Configuration const settings: Readonly<Settings>
API Responses const response: Readonly<ApiResponse>
State Management Readonly<AppState> in Redux / Zustand

Part 4: ReadonlyArray<T> — Immutable Array

Definition

ReadonlyArray<T> represents an immutable array where mutating actions (such as adding, deleting, or reassigning indexed values) are forbidden.

Syntax & Shorthand

// Long syntax
const array1: ReadonlyArray<T> = [];

// Shorthand syntax (most common)
const array2: readonly T[] = [];

How It Works

// ✅ ReadonlyArray
const numbers: ReadonlyArray<number> = [1, 2, 3, 4, 5];

// ❌ Cannot mutate
// numbers.push(6);  // ❌ Error: Property 'push' does not exist on 'readonly number[]'
// numbers[0] = 10;  // ❌ Error: Index signature in type only permits reading
// numbers.pop();    // ❌ Error: Property 'pop' does not exist

// ✅ Can read
console.log(numbers[0]);     // 1
console.log(numbers.length); // 5

// ✅ Can iterate
for (const num of numbers) {
    console.log(num);
}

// ✅ Can create new arrays using non-mutating methods
const doubled = numbers.map(n => n * 2);    // ✅ Returns new array
const filtered = numbers.filter(n => n > 2); // ✅ Returns new array

Real-World Example: Immutable Settings

// ✅ Immutable configuration array
const config: readonly string[] = [
    "development",
    "production",
    "testing"
];

// ✅ Function that accepts a readonly array
function processConfig(settings: readonly string[]): void {
    // Read-only access
    settings.forEach(setting => console.log(setting));
    // settings.push("staging"); // ❌ Error: Cannot mutate
}

processConfig(config);

// ✅ Return readonly array
function getDefaultRoles(): readonly string[] {
    return ["admin", "editor", "viewer"];
}

const roles = getDefaultRoles();
// roles.push("guest"); // ❌ Error: Mutation forbidden

Converting Between Mutable and Readonly

// ✅ Mutable to Readonly (Safe assignment)
const mutable: number[] = [1, 2, 3];
const readonlyArr: readonly number[] = mutable; // ✅ Allowed

// ❌ Readonly to Mutable (Direct assignment disallowed)
const readonlySource: readonly number[] = [1, 2, 3];
// const mutableTarget: number[] = readonlySource; // ❌ Error

// ✅ Clone to make a mutable array
const mutableCopy1: number[] = [...readonlySource];  // ✅ Spread clone
const mutableCopy2: number[] = readonlySource.slice(); // ✅ Slice clone

ReadonlyArray Methods Summary

Allowed (Non-Mutating) Not Allowed (Mutating)
length push()
[index] (read) pop()
forEach() shift()
map() unshift()
filter() splice()
reduce() sort()
find() reverse()
includes() [index] = value (write)

📝 Summary & Key Takeaways

Quick Comparison

Generic Purpose Syntax Example
Map<K, V> Key-value collection new Map<K, V>() new Map<string, number>()
Set<T> Unique values new Set<T>() new Set<string>()
Readonly<T> Immutable object properties Readonly<T> Readonly<User>
ReadonlyArray<T> Immutable array readonly T[] readonly string[]

🎯 Key Takeaways

  • Map<K, V>: Use when you need dictionary-like lookups where keys are objects, numbers, or complex types, rather than just simple strings.
  • Set<T>: Use when values must be strictly unique without needing explicit deduplication logic.
  • Readonly<T>: Provides shallow immutability for object properties. Use recursive mapped types like DeepReadonly for nested structures.
  • ReadonlyArray<T>: Prevents mutation on lists. Can be quickly declared using the readonly T[] shorthand.
