INTRODUCTION TO GENERICS

WRITE REUSABLE CODE THAT WORKS WITH ANY TYPE, WHILE PRESERVING TYPE SAFETY.

1. What Are Generics?

Definition:

Generics are a TypeScript feature that allows you to write reusable code that works with any type, while still preserving type safety.

The Word "Generic":

  • "Generic" means "relating to a whole group or class."
  • In TypeScript, it means: one piece of code that works for any type.

2. Why Is It Called "Generics"?

Term Meaning
Generic"Not specific; general"
In TypeScriptCode that works with any type, not just one specific type

Example:

// ❌ Specific: only works with strings
function identityString(value: string): string {
    return value;
}

// ✅ Generic: works with ANY type
function identity(value: T): T {
    return value;
}
Why the name fits:

Just like a "generic" product works for everyone, generic code works for every type.

3. The Problem: Without Generics

Problem 1: Using any

function identity(value: any): any {
    return value;
}

const result = identity("hello");
// ❌ TypeScript doesn't know 'result' is a string
result.toUpperCase(); // Works at runtime, but TypeScript can't help

Issues:

  • ❌ Type safety is lost
  • ❌ No autocomplete
  • ❌ Bugs can slip through

Problem 2: Using Specific Types

function identityString(value: string): string {
    return value;
}

function identityNumber(value: number): number {
    return value;
}

function identityBoolean(value: boolean): boolean {
    return value;
}

// 😫 We have to repeat the same logic for EVERY type!

Issues:

  • ❌ Code duplication
  • ❌ Hard to maintain
  • ❌ Not reusable

🟢 4. The Solution: Generics

The Same Example, With Generics.
we'll learn working with generics function in next chapter but this is just for example.

function identity(value: T): T {
    return value;
}
<T>"I’m going to use a type called T"
value: T"The argument is of type T"
: T"The return value is of type T"
T is replacedWhen you call the function, T becomes the actual type

Usage

const result = identity("hello"); // TypeScript knows: string
const result2 = identity(42);     // TypeScript knows: number
const result3 = identity(true);   // TypeScript knows: boolean

// We can also pass a specific type
const result4 = identity("hiii");

here the string is passes into T.

How It Works (Step by Step)

// Step 1: You write the generic function
function identity(value: T): T {
    return value;
}

// Step 2: You call it with a string
identity("hello");

// Step 3: TypeScript replaces T with string
function identity(value: string): string {
    return value;
}

// Step 4: You call it with a number
identity(42);

// Step 5: TypeScript replaces T with number
function identity(value: number): number {
    return value;
}
Think of it like this:

Generics are like function parameters, but for types instead of values.

// Value parameter
function add(a: number, b: number): number {
    return a + b;
}
add(5, 10); // 5 and 10 are the VALUES passed

// Type parameter
function identity(value: T): T {
    return value;
}
identity("hello"); // string is the TYPE passed

🧩 7. Generics in Types (Type Aliases)

Example 1: Box Type

type Box = {
    value: T;
};

// Usage:
const stringBox: Box = { value: "hello" };
const numberBox: Box = { value: 42 };
const booleanBox: Box = { value: true };

Example 2: Nullable Type

type Nullable = T | null;

// Usage:
let name: Nullable = "Alice";
name = null; // ✅ Allowed

Example 3: Pair Type

type Pair = {
    first: T;
    second: U;
};

// Usage:
const pair: Pair = {
    first: "hello",
    second: 42
};

here the string passes into T and number passes into U, so the type becomes:

type Pair = {
    first: string;
    second: number;
};

Example 4: Array Wrapper

type ArrayWrapper = T[];

// Usage:
const numbers: ArrayWrapper = [1, 2, 3];
const names: ArrayWrapper = ["Arman", "Khan","Munnu"];

Example 5: ApiResponse Type

type ApiResponse = {
    status: number;
    data: T;
    message: string;
};

// Usage:
type User = { id: number; name: string };
const response: ApiResponse = {
    status: 200,
    data: { id: 1, name: "Alice" },
    message: "Success"
};

8. Generics in Interfaces

Syntax

interface InterfaceName {
    // Use T here
}

Example 1: Box Interface

interface Box {
    value: T;
    getValue(): T;
}

// Usage:
const stringBox: Box = {
    value: "Munnu",
    getValue() {
        return this.value;
    }
};

console.log(stringBox.getValue()); // "Munnu"

Example 2: Repository Interface

interface Repository {
    items: T[];
    add(item: T): void;
    get(index: number): T | undefined;
    getAll(): T[];
}

let userRepo: Repository = {
    items: [],
    add(item: string) {
        this.items.push(item)
    },
    get(index: number) {
        return this.items[index]
    },
    getAll() {
        return this.items
    },
}

userRepo.add("Mnnnu");
userRepo.add("Shunnu");
console.log(userRepo.getAll()); // ['Munnu','Shunnu']
