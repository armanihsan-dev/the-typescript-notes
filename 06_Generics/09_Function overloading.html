FUNCTION OVERLOADING

COMPLETE GUIDE: DEFINING MULTIPLE CALL SIGNATURES SAFELY

Part 1: What is Function Overloading?

Definition

Function overloading is a TypeScript feature that allows a single function name to declare multiple type signatures. This enables a function to accept different combinations of parameter types, parameter counts, or return types while maintaining strict type safety at call sites.

The Core Idea

// ❌ Without overloading: single signature restricts flexible inputs
function greet(name: string): string {
    return `Hello ${name}`;
}
greet("Alice"); // ✅ Works
greet(42);      // ❌ Error: Argument of type 'number' is not assignable to 'string'

// ✅ With overloading: multiple signatures declare valid callers
function greet(name: string): string;
function greet(age: number): string;
function greet(value: string | number): string {
    if (typeof value === "string") {
        return `Hello ${value}`;
    }
    return `You are ${value} years old`;
}

greet("Alice"); // ✅ "Hello Alice"
greet(25);      // ✅ "You are 25 years old"

Part 3: Syntax: Overload Signatures + Implementation

The Anatomy: Overloads vs. Implementation

// 1. Overload Signatures (Public visible API signatures)
function process(value: string): string;
function process(value: number): number;
function process(value: boolean): boolean;

// 2. Implementation Signature (Internal logic — not callable directly!)
function process(value: string | number | boolean): string | number | boolean {
    if (typeof value === "string") return value.toUpperCase();
    if (typeof value === "number") return value * 2;
    return !value;
}

Part 4: Practical Examples

Example 1: Handling Different Parameter Types

// Overloads
function format(value: string): string;
function format(value: number): string;
function format(value: Date): string;

// Implementation
function format(value: string | number | Date): string {
    if (typeof value === "string") return value;
    if (typeof value === "number") return value.toFixed(2);
    return value.toISOString();
}

// Usage
format("hello");    // ✅ Returns "hello"
format(42.123);     // ✅ Returns "42.12"
format(new Date()); // ✅ Returns "2024-01-01T00:00:00.000Z"

Example 2: Varying Parameter Counts (Arity)

// Overloads
function createElement(tag: string): HTMLElement;
function createElement(tag: string, className: string): HTMLElement;
function createElement(tag: string, className: string, id: string): HTMLElement;

// Implementation with optional parameters
function createElement(
    tag: string,
    className?: string,
    id?: string
): HTMLElement {
    const element = document.createElement(tag);
    if (className) element.className = className;
    if (id) element.id = id;
    return element;
}

// Usage
const div1 = createElement("div");                     // ✅ Allowed
const div2 = createElement("div", "container");        // ✅ Allowed
const div3 = createElement("div", "container", "app"); // ✅ Allowed
// const div4 = createElement("div", "container", "app", "extra"); // ❌ Compile Error!

Part 6: Common Causes & Solutions

Cause 1: Incorrect Argument Type

// Overloads
function getLength(value: string): number;
function getLength(value: number[]): number;
function getLength(value: any): number {
    return value.length;
}

// ❌ Error: No overload matches this call
getLength(true); // boolean is not string or number[]

// ✅ Fix: Only call with allowed types
getLength("hello");   // ✅
getLength([1, 2, 3]); // ✅

Cause 2: Missing Overload for a Valid Use Case

// Overloads
function process(value: string): string;
function process(value: number): number;
function process(value: any): any {
    return value;
}

// ❌ Error: No overload matches this call
process(true); // boolean not declared in overload signatures

// ✅ Fix: Add an overload signature for boolean
function process(value: string): string;
function process(value: number): number;
function process(value: boolean): boolean; // Added
function process(value: any): any {
    return value;
}

process(true); // ✅ Works

Cause 3: Incorrect Argument Count

// Overloads
function log(message: string): void;
function log(message: string, level: string): void;
function log(message: string, level?: string): void {
    console.log(`[${level || "INFO"}] ${message}`);
}

// ❌ Error: No overload matches this call
log("hello", "INFO", "extra"); // 3 arguments passed, but max supported is 2

// ✅ Fix: Call within allowed arity
log("hello");         // ✅
log("hello", "INFO"); // ✅

Cause 4: Incorrect Generic / Return Signatures

// ❌ Overloads without bodies must terminate with a semicolon
// function getValue<T>(key: string): T
// function getValue(key: string): any { return data[key]; }

// ✅ Correct overload pattern:
function getValue(key: "id"): number;
function getValue(key: "name"): string;
function getValue(key: string): any {
    return (data as any)[key];
}

const id = getValue("id");     // Inferred as number
const name = getValue("name"); // Inferred as string
