Property Selection Utility Types — Pick and Omit

🎯 What Are Property Selection Utility Types?

Definition:

Property selection utility types let you create a new type by selecting or removing specific properties from an existing type.

They are:

  • Pick<T, K> — selects specific properties
  • Omit<T, K> — removes specific properties

The Core Idea

┌─────────────────────────────────────────────────────────────────┐
│                    PROPERTY SELECTION                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Original Type:                                                 │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  type User = {                                          │   │
│  │      id: number;                                        │   │
│  │      name: string;                                      │   │
│  │      email: string;                                     │   │
│  │      password: string;                                  │   │
│  │  }                                                      │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Pick<User, "id" | "name">:                                     │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { id: number; name: string }                           │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Omit<User, "password">:                                        │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { id: number; name: string; email: string }            │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

1. 🎯 Pick<T, K> — Select Specific Properties

Definition

Pick<T, K> creates a new type by selecting only the properties K from type T.

Syntax

type Pick<T, K extends keyof T> = {
    [P in K]: T[P];
};

How It Works

interface User {
    id: number;
    name: string;
    email: string;
    password: string;
}

type UserBasic = Pick<User, "id" | "name">;
// {
//     id: number;
//     name: string;
// }

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    HOW Pick WORKS                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Pick<User, "id" | "name">                                      │
│                                                                  │
│  Step 1: keyof User = "id" | "name" | "email" | "password"     │
│                                                                  │
│  Step 2: K = "id" | "name"                                     │
│                                                                  │
│  Step 3: For each key in K, include it                        │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  "id"   → id: number                                    │   │
│  │  "name" → name: string                                  │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 4: Exclude all other keys                               │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  "email"    → ❌ Not included                            │   │
│  │  "password" → ❌ Not included                            │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Result: { id: number; name: string }                          │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Example

interface User {
    id: number;
    name: string;
    email: string;
    password: string;
}

// Pick only id and name
type UserBasic = Pick<User, "id" | "name">;
// { id: number; name: string }

// Pick only email
type UserEmail = Pick<User, "email">;
// { email: string }

// ✅ Works
const basicUser: UserBasic = {
    id: 1,
    name: "Alice"
};

// ❌ Error: email is not in UserBasic
const invalid: UserBasic = {
    id: 1,
    name: "Alice",
    email: "alice@email.com" // Error
};

Use Case: Public API Response

interface User {
    id: number;
    name: string;
    email: string;
    password: string;
    createdAt: Date;
    updatedAt: Date;
}

// Only expose public fields
type PublicUser = Pick<User, "id" | "name" | "email">;

function getPublicUser(user: User): PublicUser {
    return {
        id: user.id,
        name: user.name,
        email: user.email
    };
}

// ✅ No password exposed!

Use Case: Form Fields

interface Product {
    id: number;
    name: string;
    price: number;
    description: string;
    category: string;
    inStock: boolean;
}

// Only fields for the form
type ProductForm = Pick<Product, "name" | "price" | "description">;

const form: ProductForm = {
    name: "Laptop",
    price: 999.99,
    description: "Powerful laptop"
};

2. 🎯 Omit<T, K> — Remove Specific Properties

Definition

Omit<T, K> creates a new type by removing the properties K from type T.

Syntax

type Omit<T, K extends keyof any> = Pick<T, Exclude<keyof T, K>>;

How It Works

interface User {
    id: number;
    name: string;
    email: string;
    password: string;
}

type UserWithoutPassword = Omit<User, "password">;
// {
//     id: number;
//     name: string;
//     email: string;
// }

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    HOW Omit WORKS                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Omit<User, "password">                                         │
│                                                                  │
│  Step 1: keyof User = "id" | "name" | "email" | "password"     │
│                                                                  │
│  Step 2: K = "password"                                        │
│                                                                  │
│  Step 3: Remove "password" from keys                           │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  "id"       → keep                                      │   │
│  │  "name"     → keep                                      │   │
│  │  "email"    → keep                                      │   │
│  │  "password" → ❌ Remove                                 │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 4: Build new type with remaining keys                   │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { id: number; name: string; email: string }            │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Example

interface User {
    id: number;
    name: string;
    email: string;
    password: string;
}

// Omit password
type UserWithoutPassword = Omit<User, "password">;
// { id: number; name: string; email: string }

// ✅ Works
const safeUser: UserWithoutPassword = {
    id: 1,
    name: "Alice",
    email: "alice@email.com"
};

// ❌ Error: password is not allowed
const invalid: UserWithoutPassword = {
    id: 1,
    name: "Alice",
    email: "alice@email.com",
    password: "secret" // Error
};

Use Case: Form Data (Without ID)

interface User {
    id: number;
    name: string;
    email: string;
    password: string;
    createdAt: Date;
    updatedAt: Date;
}

// For creating a new user (no id or timestamps)
type CreateUserData = Omit<User, "id" | "createdAt" | "updatedAt">;

const newUser: CreateUserData = {
    name: "Alice",
    email: "alice@email.com",
    password: "secret123"
};

// ✅ No id needed
// ✅ No timestamps needed

Use Case: Update Payload

interface User {
    id: number;
    name: string;
    email: string;
    password: string;
}

// For updating (no id, all other fields optional)
type UpdateUserData = Partial<Omit<User, "id">>;

const updates: UpdateUserData = {
    name: "Bob"
    // email and password optional
};

🧠 Pick vs Omit — When to Use Which

┌─────────────────────────────────────────────────────────────────┐
│                    Pick vs Omit                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Pick<T, K>:                                                    │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  "I only want THESE properties"                          │   │
│  │                                                         │   │
│  │  Use when you know exactly what you need               │   │
│  │  Example: Pick<User, "id" | "name">                    │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Omit<T, K>:                                                    │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  "I want EVERYTHING EXCEPT these properties"            │   │
│  │                                                         │   │
│  │  Use when you know what you DON'T need                 │   │
│  │  Example: Omit<User, "password">                       │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

When to Use Pick

Use Pick When Example
You need a small subset of properties Pick<User, "id" | "name">
The original type has many properties Picking 2 out of 20
You want explicit control List exactly what you need

When to Use Omit

Use Omit When Example
You need most properties except a few Omit<User, "password">
You want to remove sensitive data Omit password, token
The original type has few properties Omit 2 out of 5

📝 Summary Table

Utility Type What It Does Syntax Example
Pick<T, K> Selects specific properties Pick<T, K extends keyof T> Pick<User, "id" | "name">
Omit<T, K> Removes specific properties Omit<T, K extends keyof any> Omit<User, "password">

🎯 Key Takeaways

Concept Explanation
Pick Keeps only specified properties
Omit Removes specified properties
How they work Built with mapped types + keyof
When to use Pick Need a small subset
When to use Omit Need most properties, remove a few

🧪 Practice Exercises

// 1. Pick only id and name
interface User {
    id: number;
    name: string;
    email: string;
    password: string;
}
type UserBasic = Pick<User, "id" | "name">;
// { id: number; name: string }

// 2. Omit password
type UserSafe = Omit<User, "password">;
// { id: number; name: string; email: string }

// 3. Combine Pick and Omit
type UserNameAndEmail = Pick<Omit<User, "password">, "name" | "email">;
// { name: string; email: string }

// 4. Pick only specific form fields
interface Product {
    id: number;
    name: string;
    price: number;
    description: string;
    category: string;
}
type ProductForm = Pick<Product, "name" | "price" | "description">;
// { name: string; price: number; description: string }

// 5. Omit id and timestamps for create
interface Post {
    id: number;
    title: string;
    body: string;
    createdAt: Date;
    updatedAt: Date;
}
type CreatePost = Omit<Post, "id" | "createdAt" | "updatedAt">;
// { title: string; body: string }
