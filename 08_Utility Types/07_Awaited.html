Awaited<T> — Complete Guide

🎯 What is Awaited<T>?

Definition:

Awaited<T> is a built-in utility type that extracts the resolved type from a Promise. It "unwraps" the Promise to reveal what's inside — and it does this recursively for nested Promises.

The One-Line Summary

type Result = Awaited<Promise<string>>;
// Result = string

🧠 The Mental Model

┌─────────────────────────────────────────────────────────────────┐
│                    Awaited<T>                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Think of a Promise as a "box" that holds a value.             │
│  Awaited<T> opens the box and gives you the value.             │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Promise<string>  →  open the box  →  string            │   │
│  │  Promise<number>  →  open the box  →  number            │   │
│  │  Promise<User>    →  open the box  →  User              │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  For nested promises, it opens ALL the boxes:                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Promise<Promise<string>>  →  string                    │   │
│  │  Promise<Promise<Promise<number>>>  →  number           │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 1: Basic Syntax

type Result = Awaited<Promise<T>>;

Simple Examples

type A = Awaited<Promise<string>>;  // string
type B = Awaited<Promise<number>>;  // number
type C = Awaited<Promise<boolean>>; // boolean
type D = Awaited<Promise<User>>;    // User

With Non-Promise Types

// If T is not a Promise, Awaited returns T unchanged
type E = Awaited<string>;  // string
type F = Awaited<number>;  // number
type G = Awaited<boolean>; // boolean

Part 2: How It Works

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    HOW Awaited WORKS                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Awaited<Promise<string>>                                       │
│                                                                  │
│  Step 1: Is it a Promise?                                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Promise<string> extends Promise<infer U>?             │   │
│  │  YES → U = string                                       │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Is U also a Promise? (recursion)                     │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  string extends Promise<infer V>?                       │   │
│  │  NO → return string                                     │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Result: string                                                 │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Nested Promises

┌─────────────────────────────────────────────────────────────────┐
│                    NESTED PROMISES                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Awaited<Promise<Promise<string>>>                              │
│                                                                  │
│  Step 1: Outer Promise → U = Promise<string>                   │
│  Step 2: Inner Promise → V = string                            │
│  Step 3: string is not a Promise → return string              │
│                                                                  │
│  Result: string                                                 │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 3: Real-World Examples

Example 1: Async Function Return Type

async function fetchUser(): Promise<{ id: number; name: string }> {
    return { id: 1, name: "Alice" };
}

// ❌ ReturnType gives Promise<{ id: number; name: string }>
type RawReturn = ReturnType<typeof fetchUser>;

// ✅ Awaited unwraps it
type User = Awaited<ReturnType<typeof fetchUser>>;
// { id: number; name: string }

// Now you can use it
const user: User = { id: 1, name: "Alice" };

Example 2: API Client

interface ApiClient {
    get<T>(url: string): Promise<T>;
    post<T>(url: string, body: unknown): Promise<T>;
}

async function fetchUsers(): Promise<User[]> {
    return [];
}

// Extract the resolved type
type Users = Awaited<ReturnType<typeof fetchUsers>>;
// User[]

Example 3: Nested Async Operations

async function getData(): Promise<Promise<string>> {
    return Promise.resolve("hello");
}

type Data = Awaited<ReturnType<typeof getData>>;
// string (unwraps BOTH promises)

Example 4: Promise.all with Awaited

async function fetchUser(): Promise<User> {
    return {} as User;
}

async function fetchPosts(): Promise<Post[]> {
    return [];
}

async function fetchAll() {
    const [user, posts] = await Promise.all([
        fetchUser(),
        fetchPosts()
    ]);
    return { user, posts };
}

type AllData = Awaited<ReturnType<typeof fetchAll>>;
// { user: User; posts: Post[] }

Part 4: Internal Implementation

Simplified Version

type MyAwaited<T> = T extends Promise<infer U> ? MyAwaited<U> : T;

How It Works

┌─────────────────────────────────────────────────────────────────┐
│                    INTERNAL IMPLEMENTATION                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  type MyAwaited<T> =                                           │
│      T extends Promise<infer U>                                │
│          ? MyAwaited<U>    // ← Recursive case                 │
│          : T;               // ← Base case                     │
│                                                                  │
│  For Promise<string>:                                          │
│  1. Promise<string> extends Promise<infer U> → U = string      │
│  2. string extends Promise<infer U> → NO                       │
│  3. Return string                                              │
│                                                                  │
│  For Promise<Promise<string>>:                                 │
│  1. Promise<Promise<string>> extends Promise<infer U>          │
│     → U = Promise<string>                                      │
│  2. Promise<string> extends Promise<infer U> → U = string      │
│  3. string extends Promise<infer U> → NO                       │
│  4. Return string                                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Full TypeScript Implementation

// The actual TypeScript implementation is more complex
// because it handles thenables, null, undefined, etc.

type Awaited<T> = T extends null | undefined 
    ? T 
    : T extends object & { then(onfulfilled: infer F, ...args: infer _): any }
        ? F extends ((value: infer V, ...args: infer _) => any)
            ? Awaited<V>
            : never
        : T;

Part 5: Awaited vs ReturnType

The Difference

Utility Type What It Does Example
ReturnType<T> Gets the return type of a function ReturnType<typeof fn> → Promise<User>
Awaited<T> Unwraps a Promise Awaited<Promise<User>> → User

Together

async function fetchUser(): Promise<User> {
    return {} as User;
}

// Step 1: Get return type
type RawReturn = ReturnType<typeof fetchUser>;
// Promise<User>

// Step 2: Unwrap the Promise
type UserType = Awaited<RawReturn>;
// User

// Or in one line:
type UserType2 = Awaited<ReturnType<typeof fetchUser>>;
// User
