Combining Multiple Utility Types — Complete Guide

🎯 What Does "Combining Utility Types" Mean?

Definition:

Combining utility types means using the output of one utility type as the input of another. Since utility types are just type transformations, you can chain them together to build exactly the type you need.

The Core Idea

┌─────────────────────────────────────────────────────────────────┐
│                    COMBINING UTILITY TYPES                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Single utility type:                                           │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  User  →  Pick<User, "id" | "name">  →  Final Type      │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Combined utility types:                                        │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  User  →  Pick<User, ...>  →  Readonly<...>  →  Final   │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Each utility type takes the previous result as input.         │
│  This is called COMPOSITION.                                   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

🧠 Why Do We Combine Utility Types?

Because one utility type is often not enough.

Goal Single Utility Combined
Pick properties AND make readonly ❌ Not possible ✅ Readonly<Pick<T, K>>
Remove properties AND make optional ❌ Not possible ✅ Partial<Omit<T, K>>
Get return type AND make readonly ❌ Not possible ✅ Readonly<ReturnType<T>>
Remove union member AND create record ❌ Not possible ✅ Record<Exclude<T, U>, V>

1. 🔒 Pick + Readonly

Goal

Pick only id and name, and make them readonly.

The Code

type User = {
    id: number;
    name: string;
    email: string;
    password: string;
};

type ReadonlyPublicUser = Readonly<Pick<User, "id" | "name">>;

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    Pick + Readonly                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: Pick<User, "id" | "name">                             │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { id: number; name: string }                           │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Readonly<...>                                         │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { readonly id: number; readonly name: string }         │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Result

type ReadonlyPublicUser = {
    readonly id: number;
    readonly name: string;
};

Use Case

Public API response where only id and name are exposed, and they can't be modified.

2. ✂️ Omit + Partial

Goal

Remove id and make all remaining properties optional.

The Code

type PartialUserUpdate = Partial<Omit<User, "id">>;

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    Omit + Partial                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: Omit<User, "id">                                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { name: string; email: string; password: string }      │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Partial<...>                                          │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { name?: string; email?: string; password?: string }   │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Result

type PartialUserUpdate = {
    name?: string;
    email?: string;
    password?: string;
};

Use Case

Update payloads where you only send the fields that changed, and id is never sent.

3. 🧾 Record + Readonly

Goal

Create a readonly permissions object.

The Code

type Role = "admin" | "user" | "guest";

type Permissions = Readonly<Record<Role, boolean>>;

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    Record + Readonly                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: Record<Role, boolean>                                 │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { admin: boolean; user: boolean; guest: boolean }      │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Readonly<...>                                         │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { readonly admin: boolean; readonly user: boolean;     │   │
│  │    readonly guest: boolean }                            │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Result

type Permissions = {
    readonly admin: boolean;
    readonly user: boolean;
    readonly guest: boolean;
};

Use Case

Configuration objects that should never be modified after creation.

4. 🔀 Exclude + Record

Goal

Remove guest and create a permissions object only for admin and user.

The Code

type Role = "admin" | "user" | "guest";

type Permissions = Record<Exclude<Role, "guest">, boolean>;

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    Exclude + Record                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: Exclude<Role, "guest">                                │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  "admin" | "user"                                       │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Record<"admin" | "user", boolean>                     │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { admin: boolean; user: boolean }                      │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Result

type Permissions = {
    admin: boolean;
    user: boolean;
};

Use Case

Excluding roles that don't have certain permissions.

5. 🧠 Extract + Record

Goal

Keep only admin and user, and create a settings object.

The Code

type Role = "admin" | "user" | "guest";

type Settings = Record<Extract<Role, "admin" | "user">, string>;

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    Extract + Record                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: Extract<Role, "admin" | "user">                       │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  "admin" | "user"                                       │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Record<"admin" | "user", string>                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { admin: string; user: string }                        │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Result

type Settings = {
    admin: string;
    user: string;
};

Use Case

Selecting only specific roles for a settings page.

6. ⚙️ ReturnType + Readonly

Goal

Get the return type of a function and make it readonly.

The Code

function createUser() {
    return {
        id: 1,
        name: "Anurag"
    };
}

type ReadonlyUser = Readonly<ReturnType<typeof createUser>>;

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    ReturnType + Readonly                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: ReturnType<typeof createUser>                         │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { id: number; name: string }                           │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Readonly<...>                                         │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { readonly id: number; readonly name: string }         │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Result

type ReadonlyUser = {
    readonly id: number;
    readonly name: string;
};

Use Case

Factory functions that return immutable objects.

7. ⚙️ Parameters + Partial

Goal

Get the function parameter type and make all properties optional.

The Code

function createUser(user: {
    name: string;
    age: number;
}) {}

type PartialUser = Partial<Parameters<typeof createUser>[0]>;

why the [0] at last ?

Parameters<typeof createUser2> gives you a tuple of the function’s parameter types: 

[{ name: string; age: number }]

The [0] selects the type of the first parameter from that tuple. Then Partial makes its properties optional: 

type PartialUser = Partial<{ name: string; age: number }>
// { name?: string; age?: number }

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    Parameters + Partial                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: Parameters<typeof createUser>                         │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  [{ name: string; age: number }]                        │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Parameters<typeof createUser>[0]                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { name: string; age: number }                          │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 3: Partial<...>                                          │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { name?: string; age?: number }                        │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Result

type PartialUser = {
    name?: string;
    age?: number;
};

Use Case

Reusing function parameter types for update payloads.

🧠 The Composition Pattern

┌─────────────────────────────────────────────────────────────────┐
│                    COMPOSITION PATTERN                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Original Type                                                 │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  User                                                   │   │
│  └──────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│  Step 1: Pick<User, "id" | "name">                            │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { id: number; name: string }                           │   │
│  └──────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│  Step 2: Readonly<...>                                         │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  { readonly id: number; readonly name: string }         │   │
│  └──────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│  Final Type                                                    │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  ReadonlyPublicUser                                     │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

📝 Summary Table

Combination What It Does Example
Pick + Readonly Pick properties and make readonly Readonly<Pick<User, "id" | "name">>
Omit + Partial Remove properties and make optional Partial<Omit<User, "id">>
Record + Readonly Create readonly record Readonly<Record<Role, boolean>>
Exclude + Record Remove union member and create record Record<Exclude<Role, "guest">, boolean>
Extract + Record Keep union members and create record Record<Extract<Role, "admin" | "user">, string>
ReturnType + Readonly Get return type and make readonly Readonly<ReturnType<typeof fn>>
Parameters + Partial Get params and make optional Partial<Parameters<typeof fn>[0]>

🎯 Key Takeaways

Concept Explanation
Composition Output of one utility type is input to another
Order matters Readonly<Pick<T, K>> ≠ Pick<Readonly<T>, K>
When to combine When one utility type isn't enough
Common patterns Pick + Readonly, Omit + Partial, Record + Readonly
Real-world use API responses, update payloads, config objects

🧪 Practice Exercises

// 1. Pick + Readonly
type ReadonlyPublicUser = Readonly<Pick<User, "id" | "name">>;

// 2. Omit + Partial
type PartialUserUpdate = Partial<Omit<User, "id">>;

// 3. Record + Readonly
type Permissions = Readonly<Record<"admin" | "user" | "guest", boolean>>;

// 4. Exclude + Record
type AdminPermissions = Record<Exclude<"admin" | "user" | "guest", "guest">, boolean>;

// 5. Extract + Record
type Settings = Record<Extract<"admin" | "user" | "guest", "admin" | "user">, string>;

// 6. ReturnType + Readonly
function createUser() {
    return { id: 1, name: "Anurag" };
}
type ReadonlyUser = Readonly<ReturnType<typeof createUser>>;

// 7. Parameters + Partial
function updateUser(user: { name: string; age: number }) {}
type PartialUpdate = Partial<Parameters<typeof updateUser>[0]>;

// 8. Three-level combination
type DeepReadonlyPublicUser = Readonly<Pick<User, "id" | "name">>;
