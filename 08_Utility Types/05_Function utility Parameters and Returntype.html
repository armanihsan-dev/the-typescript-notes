Function Utility Types

Parameters<T> and ReturnType<T>

🎯 What Are Function Utility Types?

Definition: Built-in TypeScript types that extract information from function types at the type level.

Utility Type What It Does
Parameters<T> Gets the parameter types of a function as a tuple
ReturnType<T> Gets the return type of a function

📦 1. Parameters<T> — Get Function Parameters

Definition: Extracts the parameter types of function type T as a tuple type.

Syntax (Internal Implementation)

type Parameters<T extends (...args: any) => any> = 
    T extends (...args: infer P) => any ? P : never;

Basic Example

function greet(name: string, age: number): string {
    return `Hello ${name}, ${age}`;
}

type GreetParams = Parameters<typeof greet>;
// [string, number]

How It Works (Mental Model)

Parameters<typeof greet>
  Step 1: typeof greet = (name: string, age: number) => string
  Step 2: Match against (...args: infer P) => any
          → P = [string, number]
  Step 3: Return P → [string, number]

⚠️ Key: Use typeof for Functions

You must pass typeof greet, not greet — because Parameters<T> expects a type, not a value.

📋 Examples by Function Type

Function Type Example Result of Parameters
Basic add(a: number, b: number) [number, number]
Optional param greet(name: string, age?: number) [string, number?]
Rest params sum(...numbers: number[]) number[]
No params noParams() []
Arrow fn multiply = (a: number, b: number) => a * b [number, number]

🔧 Use Cases

1. Wrapper Functions

function logAndCall<T extends (...args: any[]) => any>(
    fn: T,
    ...args: Parameters<T>
): ReturnType<T> {
    console.log(`Calling ${fn.name} with:`, args);
    return fn(...args);
}

const result = logAndCall(add, 5, 10);
// ✅ args must be [number, number], result is number

2. Higher-Order Functions (Debounce)

function createDebounced<T extends (...args: any[]) => any>(
    fn: T, delay: number
): (...args: Parameters<T>) => void {
    // ...
}

3. Type-Safe Event Handlers

type EventHandler = (event: MouseEvent, data: { x: number; y: number }) => void;
// Reuse Parameters<EventHandler> to preserve signature

📦 2. ReturnType<T> — Get Function Return Type

Definition: Extracts the return type of function type T.

Syntax (Internal Implementation)

type ReturnType<T extends (...args: any) => any> = 
    T extends (...args: any) => infer R ? R : any;

Basic Example

function greet(name: string): string {
    return `Hello ${name}`;
}

type GreetReturn = ReturnType<typeof greet>;
// string

How It Works (Mental Model)

ReturnType<typeof greet>
  Step 1: typeof greet = (name: string) => string
  Step 2: Match against (...args: any) => infer R
          → R = string
  Step 3: Return R → string

📋 Examples by Return Type

Function Returns Example Result of ReturnType
Primitive add(a, b): number number
Object createUser() (inferred) { id: number; name: string; createdAt: Date }
Async async fetchUser(): Promise<{name:string}> Promise<{ name: string }>
Union getStatus(): "pending" | "success" | "failed" "pending" | "success" | "failed"
Void log(message: string): void void

🔧 Use Cases

1. Extract API Response Types

async function fetchUsers(): Promise<User[]> { /* ... */ }

// ReturnType alone gives Promise<User[]>, so combine with Awaited:
type Users = Awaited<ReturnType<typeof fetchUsers>>;
// User[]

💡 Note: For async functions, wrap in Awaited<> to unwrap the Promise.

2. Redux Action Types

const actions = {
    increment: (amount: number) => ({ type: "INCREMENT", payload: amount }),
    decrement: (amount: number) => ({ type: "DECREMENT", payload: amount }),
    reset: () => ({ type: "RESET" })
};

type ActionCreators = typeof actions;
type Action = ReturnType<ActionCreators[keyof ActionCreators]>;
// { type: "INCREMENT"; payload: number }
// | { type: "DECREMENT"; payload: number }
// | { type: "RESET" }

3. Type-Safe Factory

function createUser(name: string, age: number) {
    return { id: /*...*/, name, age, createdAt: new Date() };
}

type User = ReturnType<typeof createUser>;

function processUser(user: User): void { /* ... */ }

🧠 Parameters + ReturnType Together

Function Wrapper

function withLogging<T extends (...args: any[]) => any>(
    fn: T
): (...args: Parameters<T>) => ReturnType<T> {
    return (...args: Parameters<T>): ReturnType<T> => {
        console.log(`Calling ${fn.name} with:`, args);
        const result = fn(...args);
        console.log(`Result:`, result);
        return result;
    };
}
// ✅ Preserves both args and return types perfectly

Type-Safe Curry

function curry<T extends (...args: any[]) => any>(
    fn: T
): (arg: Parameters<T>[0]) => (
    ...args: Parameters<T> extends [any, ...infer Rest] ? Rest : never
) => ReturnType<T> {
    return (arg) => (...rest) => fn(arg, ...rest);
}
