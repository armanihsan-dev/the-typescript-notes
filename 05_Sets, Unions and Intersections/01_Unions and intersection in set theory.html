Part 1: What are Unions and Intersections?

The Big Picture

Unions and intersections are two fundamental operations you can perform on sets. They allow you to combine or overlap sets to create new sets.

┌─────────────────────────────────────────────────────────────────────┐
│                    THE TWO OPERATIONS                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  UNION (∪)                                                         │
│  "Everything in A OR in B"                                         │
│  → Combines ALL elements from both sets                           │
│  → No duplicates!                                                 │
│                                                                     │
│  INTERSECTION (∩)                                                  │
│  "Everything in A AND in B"                                        │
│  → Elements that are SHARED between both sets                     │
│  → Only common elements!                                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

Part 2: Union of Sets (A ∪ B)

Definition

The union of two sets A and B (written as A ∪ B) is the set of all elements that are in A, OR in B, OR in both.

Formula

A ∪ B = { x | x ∈ A OR x ∈ B }

Read as: "The set of all x such that x is in A OR x is in B"

Key Points

  • "OR" in math means inclusive OR (either, or both)
  • No element appears twice (duplicates are removed)
  • If an element is in both sets, it appears only once in the union

Part 3: Intersection of Sets (A ∩ B)

Definition

The intersection of two sets A and B (written as A ∩ B) is the set of all elements that are in BOTH A and B.

Formula

A ∩ B = { x | x ∈ A AND x ∈ B }

Read as: "The set of all x such that x is in A AND x is in B"

Key Points

  • "AND" means the element must be in both sets
  • Only common elements are included
  • If sets have no common elements, the intersection is empty (∅)
  • The intersection is always a subset of both A and B

Part 6: Union and Intersection in TypeScript

TypeScript Representations

Set Operation Mathematical Symbol TypeScript Syntax
UnionA ∪ BA | B
IntersectionA ∩ BA & B

Examples

1. Union in TypeScript (|)

type A = 1 | 2 | 3 | 4 | 5;
type B = 4 | 5 | 6 | 7 | 8;

type Union = A | B;  // 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8

2. Intersection in TypeScript (&)

type A = 1 | 2 | 3 | 4 | 5;
type B = 4 | 5 | 6 | 7 | 8;

type Intersection = A & B;  // 4 | 5

3. Union with Objects

type HasName = { name: string };
type HasAge = { age: number };

// Union: Must have either name OR age
type UnionType = HasName | HasAge;

let person1: UnionType = { name: "Alice" };  // ✅
let person2: UnionType = { age: 25 };        // ✅
let person3: UnionType = { name: "Bob", age: 30 };  // ✅

// Intersection: Must have BOTH name AND age
type IntersectionType = HasName & HasAge;

let person4: IntersectionType = { name: "Alice", age: 25 };  // ✅
let person5: IntersectionType = { name: "Alice" };  // ❌ Error: missing age
