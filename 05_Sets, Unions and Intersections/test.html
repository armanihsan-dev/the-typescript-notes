Part 1: What is a Set?

Definition

A set is a well-defined collection of distinct objects, considered as an object in its own right. The objects in a set are called elements or members of the set.

Key Characteristics

  • Well-defined – There's no ambiguity about what belongs to the set
  • Distinct – No duplicate elements (each element appears once)
  • Unordered – The order of elements doesn't matter

Syntax

Set Name : {element 1 , element 2}

Examples

{1, 2, 3} → set of numbers
{a, b, c} → set of characters
{red, green, blue} → set of colors

❌ Not a set (not well-defined)
{beautiful flowers}
👉 “beautiful” is subjective, so we can’t clearly decide
// In TypeScript (as sets of values)
type Colors = "red" | "green" | "blue";  // Set of three colors
type Numbers = 1 | 2 | 3 | 4 | 5;        // Set of five numbers
type Booleans = true | false;            // Set of two booleans

Part 2: Representation of Sets

2.1 Roster or Tabular Form

List all elements inside curly braces {}.

Example:

A = {1, 2, 3, 4, 5}
B = {red, green, blue}
C = {apple, banana, orange}

In TypeScript:

type SetA = 1 | 2 | 3 | 4 | 5;
type SetB = "red" | "green" | "blue";
type SetC = "apple" | "banana" | "orange";

2.2 Set Builder Form

Describe the elements using a rule or condition.

Syntax: { x | condition(x) }
Read as: "The set of all x such that condition(x) is true"

Examples:

A = { x | x is a natural number less than 10 }
B = { x | x is a primary color }
C = { x | x is a vowel in English alphabet }

Example:
A = {1,2,3,4,5,6,7,8,9}
V = {a,e,i,o,u}

Part 3: Elements of a Set

Definition

An element (or member) is an object that belongs to a set.

Notation

  • a ∈ A means "a is an element of set A"
  • a ∉ A means "a is NOT an element of set A"

Examples

A = {1, 2, 3, 4, 5}

1 ∈ A   (1 is an element of A)
6 ∉ A   (6 is NOT an element of A)

In TypeScript:

type SetA = 1 | 2 | 3 | 4 | 5;

// TypeScript doesn't have direct "∈" operator,
// but we can check using extends

type IsElement = T extends Set ? true : false;

type Test1 = IsElement<1, SetA>;  // true
type Test2 = IsElement<6, SetA>;  // false
The "extends" keyword

The keyword extends is being used to build Conditional Types using the syntax:

T extends U ? X : Y

Think of it as: "Is T assignable to U? If yes, evaluate to X (True); if no, evaluate to Y (False)."

Part 4: Types of Sets

4.1 Empty Set (∅ or {})

Definition: A set with no elements.

∅ = {}
∅ = { x | x ≠ x }  // No element can be different from itself

In TypeScript:

type EmptySet = never;  // never = empty set
// No value can be assigned to never

4.2 Singleton Set

Definition: A set with exactly one element.

A = {5}
B = {apple}
C = {true}

In TypeScript:

type SingletonA = 5;
type SingletonB = "apple";
type SingletonC = true;

4.3 Finite Set

Definition: A set with a countable number of elements.

A = {1, 2, 3}  // 3 elements
B = {a, b, c, d}  // 4 elements
C = {red, green, blue}  // 3 elements

In TypeScript:

type FiniteA = 1 | 2 | 3;
type FiniteB = "a" | "b" | "c" | "d";
type FiniteC = "red" | "green" | "blue";

4.4 Infinite Set

Definition: A set with an uncountable number of elements.

A = {1, 2, 3, 4, ...}  // Natural numbers (infinite)
B = {..., -2, -1, 0, 1, 2, ...}  // Integers (infinite)

In TypeScript:

// TypeScript types for infinite sets
type NaturalNumbers = number;  // All numbers (infinite)
type Strings = string;         // All strings (infinite)

4.5 Equal Sets

Definition: Two sets are equal if they have exactly the same elements.

A = {1, 2, 3}
B = {3, 2, 1}  // A = B (order doesn't matter)
C = {1, 2, 3, 3}  // A = C (duplicates ignored)
D = {1, 2}  // A ≠ D (different elements)

In TypeScript:

type AreEqual = A extends B ? (B extends A ? true : false) : false;

type A = 1 | 2 | 3;
type B = 3 | 2 | 1;
type C = 1 | 2 | 3 | 3;  // Duplicates are ignored

type Test1 = AreEqual;  // true
type Test2 = AreEqual;  // true

4.6 Disjoint Sets

Definition: Two sets with NO common elements.

A = {1, 2, 3}
B = {4, 5, 6}
C = {3, 4, 5}

A and B are DISJOINT (no common elements)
A and C are NOT disjoint (share element 3)

In TypeScript:

type AreDisjoint = A extends B ? false : true;

type A = 1 | 2 | 3;
type B = 4 | 5 | 6;
type C = 3 | 4 | 5;

type Test1 = AreDisjoint;  // true
type Test2 = AreDisjoint;  // false (share 3)

5. Important Standard Sets

These are very commonly used mathematical sets.

  • 🔸 Natural Numbers
    N = {1, 2, 3, 4, ...}
    👉 Counting numbers
  • 🔸 Whole Numbers
    W = {0, 1, 2, 3, 4, ...}
    👉 Includes 0
  • 🔸 Integers
    Z = {..., -3, -2, -1, 0, 1, 2, 3, ...}
    👉 Positive + negative + zero
  • 🔸 Rational Numbers
    Q = { x : x = p/q, where p and q are integers and q ≠ 0 }
    👉 Fractions like: 1/2, 3/4, -5/2
  • 🔸 Real Numbers
    R = all rational + irrational numbers
    👉 Includes: √2, π, etc.

Part 6: Subset and Superset

6.1 Subset (⊆)

Definition: Set A is a subset of set B if every element of A is also in B.

A ⊆ B  (A is subset of B)
If A ⊆ B, then A is contained in B

Example:
A = {1, 2}
B = {1, 2, 3, 4}
A ⊆ B (true)

In TypeScript:

type IsSubset = A extends B ? true : false;

type A = 1 | 2;
type B = 1 | 2 | 3 | 4;
type C = 5 | 6;

type Test1 = IsSubset;  // true
type Test2 = IsSubset;  // false

6.2 Proper Subset (⊂)

Definition: A ⊆ B and A ≠ B.

A = {1, 2}
B = {1, 2, 3}
A ⊂ B (proper subset)

A = {1, 2}
B = {1, 2}
A ⊂ B (false - they're equal)

In TypeScript:

type IsProperSubset = A extends B ? (B extends A ? false : true) : false;

type A = 1 | 2;
type B = 1 | 2 | 3;
type C = 1 | 2;

type Test1 = IsProperSubset;  // true
type Test2 = IsProperSubset;  // false (equal sets)

6.3 Superset (⊇)

Definition: B is a superset of A if A ⊆ B.

B ⊇ A  (B is superset of A)
If B contains all elements of A

Example:
A = {1, 2}
B = {1, 2, 3, 4}
B ⊇ A (true - B contains all of A)

Part 7: Universal Set (U)

Definition

The Universal Set is the set containing ALL possible elements under consideration.

Properties:

  • Every set in the context is a subset of the universal set
  • The complement of any set is relative to the universal set

Examples

For numbers: U = ℝ (Real numbers)
For colors: U = {red, green, blue, yellow, orange, purple, ...}
For letters: U = {a, b, c, ..., z}

In TypeScript:

type UniversalSet = unknown;  // Universal set in TypeScript
// Everything is a subset of unknown

8. Important Properties of Sets

✅ 1. Order Does NOT Matter
👉 Changing the order does not change the set.

A = {1, 2, 3}
B = {3, 2, 1}
👉 These are exactly the same set

A = B

✅ 2. Repetition Does NOT Matter
👉 Duplicate elements are ignored.

A = {1, 2, 2, 3, 3, 3}
👉 This is the same as:

A = {1, 2, 3}

What is Complement?

Definition

The complement of set A (written as A' or A^c or ¬A) is the set of ALL elements in the Universal Set (U) that are NOT in A.

Simple Formula

A' = { x | x ∈ U AND x ∉ A }

Read as: "The set of all x such that x is in the Universal Set AND x is NOT in A"

Complement in TypeScript

How TypeScript Represents Complement:

// In TypeScript, complement is "everything except A"

type U = string | number | boolean | null | undefined;
type A = string | number;

// A' = Everything in U that's NOT in A
type ComplementA = Exclude;  // boolean | null | undefined

// More practical example
type Colors = "red" | "green" | "blue" | "yellow" | "orange";
type Primary = "red" | "green" | "blue";

// Complement of Primary in Colors
type Secondary = Exclude;  // "yellow" | "orange"

// Visual:
// Colors = { red, green, blue, yellow, orange }
// Primary = { red, green, blue }
// Secondary = { yellow, orange } (everything else)

Set Difference (\) and TypeScript's Exclude - Complete Guide

Part 1: What is Set Difference?

Definition

The difference of two sets A and B (written as A \ B or A - B) is the set of all elements that are in A but NOT in B.

Formula

A \ B = { x | x ∈ A AND x ∉ B }

Read as: "The set of all x such that x is in A AND x is NOT in B"

Example 1: Numbers

A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

A \ B = {1, 2, 3}

Explanation:
- A has: 1, 2, 3, 4, 5
- B has: 4, 5, 6, 7, 8
- Remove from A anything that's also in B
- 4 and 5 are in both, so remove them
- 1, 2, 3 remain → A \ B = {1, 2, 3}

Visual:

A = {1, 2, 3, 4, 5}     B = {4, 5, 6, 7, 8}

A \ B = {1, 2, 3}

┌─────────────┐     ┌─────────────┐
│     A        │     │     B        │
│  {1,2,3}     │     │  {6,7,8}    │
│     ┌────────┼─────┼────────┐    │
│     │ {4,5}  │     │        │    │
│     └────────┼─────┼────────┘    │
│              │     │              │
└──────────────┘     └──────────────┘
     A \ B                B \ A
     = {1,2,3}           = {6,7,8}

Example 2: Colors

Colors = {red, green, blue, yellow, orange, purple}
Primary = {red, green, blue}
Secondary = {orange, purple, green}  // Green is both

Colors \ Primary = {yellow, orange, purple}
Colors \ Secondary = {red, blue, yellow}

Part 6: Difference in TypeScript

The Exclude Utility Type

In TypeScript, set difference is implemented as Exclude<T, U>:

type Exclude = T extends U ? never : T;

// This reads as:
// For each type T, if T extends U (is in U), remove it (never)
// Otherwise, keep it (T)

OR

  • T: The incoming union of types you want to filter (the "source set").
  • U: The type(s) you want to get rid of (the "filter set").
  • T extends U: Does the individual union member T fit inside U?
  • ? never: If yes, evaluate to never. The never type represents an empty set in TypeScript — it gets automatically deleted from any union.
  • : T: If no, keep this specific member T.

Step-by-Step Execution Walkthrough

Let's trace what happens when TypeScript executes this exact line:

type Status = "success" | "loading" | "error";

type NonErrorStatus = Exclude;

1. TypeScript Distributes the Union

Because Status is "success" | "loading" | "error", TypeScript breaks the operation into three independent checks:

Exclude("success", "error") | Exclude("loading", "error") | Exclude("error", "error")

2. Individual Conditional Checks

  • Check 1 ("success"): Does "success" extends "error"? No. → Evaluates to: "success"
  • Check 2 ("loading"): Does "loading" extends "error"? No. → Evaluates to: "loading"
  • Check 3 ("error"): Does "error" extends "error"? Yes. → Evaluates to: never

3. Re-combining the Results

TypeScript unions the outputs together:

"success" | "loading" | never

Because never means "no value possible" (an empty set), TypeScript drops it:

"success" | "loading"
