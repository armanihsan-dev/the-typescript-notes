The infer Keyword in TypeScript

Complete Guide

🎯 What is infer?

Definition:

infer is a keyword used inside conditional types to declare a type variable and extract a type from another type. It's like pattern matching at the type level.

The One-Line Summary

type Extract<T> = T extends SomePattern<infer U> ? U : never;
//                                         ↑
//                                    "Capture this type"

🧠 The Mental Model

┌─────────────────────────────────────────────────────────────────┐
│                    infer MENTAL MODEL                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  VALUE LEVEL:              TYPE LEVEL:                          │
│  ─────────────            ────────────                          │
│                                                                  │
│  const { name } = user;   type Name = T extends                 │
│                               { name: infer N } ? N : never;    │

│  "infer is destructuring for types"                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 1: Basic Syntax

The Pattern

type SomeType<T> = T extends Pattern<infer U> ? U : never;

Syntax Breakdown

type ElementType<T> = T extends (infer U)[] ? U : never;
//                                   ↑    ↑      ↑
//                                   |    |      |
//                                   |    |      Use the captured type
//                                   |    Capture the type
//                                   Pattern to match

Simple Example

// Extract the element type of an array
type ElementType<T> = T extends (infer U)[] ? U : never;

type A = ElementType<string[]>;  // string
type B = ElementType<number[]>;  // number
type C = ElementType<boolean[]>; // boolean

Part 2: Common infer Patterns

1. Extract Array Element Type

type ElementType<T> = T extends (infer U)[] ? U : never;

type A = ElementType<string[]>; // string
type B = ElementType<number[]>; // number

2. Extract Function Return Type

type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

type A = ReturnType<() => string>; // string
type B = ReturnType<(x: number) => boolean>; // boolean

3. Extract Function Parameters

type Parameters<T> = T extends (...args: infer P) => any ? P : never;

type A = Parameters<(name: string, age: number) => void>; // [string, number]
type B = Parameters<() => void>; // []

4. Extract Promise Resolved Type

type Awaited<T> = T extends Promise<infer U> ? U : never;

type A = Awaited<Promise<string>>; // string
type B = Awaited<Promise<number>>; // number
type C = Awaited<Promise<Promise<boolean>>>; // Promise<boolean> (one level)

5. Extract Object Property Type

type PropertyType<T> = T extends { name: infer N } ? N : never;

type A = PropertyType<{ name: string; age: number }>; // string
type B = PropertyType<{ name: number }>; // number

Part 3: Multiple infer in One Type

Extracting Multiple Types

type ExtractPair<T> = T extends [infer First, infer Second] 
    ? { first: First; second: Second } 
    : never;

type A = ExtractPair<[string, number]>;
// { first: string; second: number }

type B = ExtractPair<[boolean, string]>;
// { first: boolean; second: string }

Extract from Function with Multiple Parameters

type FirstAndLast<T> = T extends (first: infer F, ...args: any[], last: infer L) => any
    ? { first: F; last: L }
    : never;

type A = FirstAndLast<(a: string, b: number, c: boolean) => void>;
// { first: string; last: boolean }

Part 4: infer with Constraints

Constraining the Inferred Type

// Only infer if it extends a specific type
type ExtractString<T> = T extends (infer U extends string)[] ? U : never;

type A = ExtractString<string[]>; // string
type B = ExtractString<number[]>; // never (number doesn't extend string)

Using infer in Multiple Positions

type ExtractPromiseAndReturn<T> = T extends Promise<infer U>
    ? U extends (...args: any[]) => infer R
        ? { resolved: U; returnType: R }
        : never
    : never;

type A = ExtractPromiseAndReturn<Promise<() => string>>;
// { resolved: () => string; returnType: string }

Part 5: Recursive infer

Deep Awaited (Nested Promises)

type DeepAwaited<T> = T extends Promise<infer U>
    ? DeepAwaited<U>
    : T;

type A = DeepAwaited<Promise<string>>; // string
type B = DeepAwaited<Promise<Promise<number>>>; // number
type C = DeepAwaited<Promise<Promise<Promise<boolean>>>>; // boolean

Flatten Array

type Flatten<T> = T extends (infer U)[]
    ? U extends any[]
        ? Flatten<U>
        : U
    : T;

type A = Flatten<number[][]>; // number
type B = Flatten<string[][][]>; // string

Deep Readonly with infer

type DeepReadonly<T> = {
    readonly [K in keyof T]: T[K] extends object
        ? T[K] extends Function
            ? T[K]
            : DeepReadonly<T[K]>
        : T[K];
};

Part 6: infer in Real-World Utility Types

1. ReturnType<T>

type ReturnType<T extends (...args: any) => any> = 
    T extends (...args: any) => infer R ? R : any;

2. Parameters<T>

type Parameters<T extends (...args: any) => any> = 
    T extends (...args: infer P) => any ? P : never;

3. ConstructorParameters<T>

type ConstructorParameters<T extends abstract new (...args: any) => any> = 
    T extends abstract new (...args: infer P) => any ? P : never;

4. InstanceType<T>

type InstanceType<T extends abstract new (...args: any) => any> = 
    T extends abstract new (...args: any) => infer R ? R : any;

5. Awaited<T>

type Awaited<T> = T extends null | undefined 
    ? T 
    : T extends object & { then(onfulfilled: infer F, ...args: infer _): any }
        ? F extends ((value: infer V, ...args: infer _) => any)
            ? Awaited<V>
            : never
        : T;

Part 7: Advanced infer Patterns

Extract Tuple Head and Tail

type Head<T extends any[]> = T extends [infer H, ...any[]] ? H : never;
type Tail<T extends any[]> = T extends [any, ...infer T] ? T : never;

type A = Head<[string, number, boolean]>; // string
type B = Tail<[string, number, boolean]>; // [number, boolean]

Extract Last Element

type Last<T extends any[]> = T extends [...any[], infer L] ? L : never;

type A = Last<[string, number, boolean]>; // boolean
type B = Last<[1, 2, 3]>; // 3

Extract Object Keys by Value Type

type KeysOfType<T, V> = {
    [K in keyof T]: T[K] extends V ? K : never;
}[keyof T];

type User = { name: string; age: number; email: string };
type StringKeys = KeysOfType<User, string>; // "name" | "email"
type NumberKeys = KeysOfType<User, number>; // "age"

Extract Function Argument Type

type FirstArgument<T> = T extends (first: infer F, ...args: any[]) => any 
    ? F 
    : never;

type A = FirstArgument<(name: string, age: number) => void>; // string

Extract from Union of Functions

type UnionReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

type Fn1 = () => string;
type Fn2 = () => number;
type Fn3 = () => boolean;

type Result = UnionReturnType<Fn1 | Fn2 | Fn3>;
// string | number | boolean (distributes)

Part 8: infer with Mapped Types

Extract Property Types

type PropertyTypes<T> = {
    [K in keyof T]: T[K] extends infer U ? U : never;
};

type User = { name: string; age: number };
type Types = PropertyTypes<User>;
// { name: string; age: number }

Extract and Transform

type Getters<T> = {
    [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type User = { name: string; age: number };
type UserGetters = Getters<User>;
// { getName: () => string; getAge: () => number }

Part 9: Common Mistakes and Solutions

Mistake 1: Using infer Outside Conditional Types

// ❌ Error: 'infer' declarations are only permitted in conditional types
type Wrong<T> = infer U;

// ✅ Fix: Use inside conditional type
type Correct<T> = T extends infer U ? U : never;

Mistake 2: Inferring from Non-Matching Types

// ❌ If T is not an array, U is never inferred
type ElementType<T> = T extends (infer U)[] ? U : never;

type A = ElementType<string>; // never (string is not an array)

// ✅ Fix: Handle non-matching case
type SafeElementType<T> = T extends (infer U)[] ? U : T;
type B = SafeElementType<string>; // string

Mistake 3: Multiple infer with Same Name

// ❌ Error: Duplicate identifier 'U'
type Wrong<T> = T extends [infer U, infer U] ? U : never;

// ✅ Fix: Use different names
type Correct<T> = T extends [infer U, infer V] ? U | V : never;

🎯 Key Takeaways

Concept Explanation
infer Captures types in conditional types
Pattern matching Like destructuring for types
Multiple infers Can extract multiple types
Constraints Can constrain inferred types
Recursive Can use recursively for deep extraction
Built-in types Used in ReturnType, Parameters, Awaited
