PROPERTY MODIFIERS IN MAPPED TYPES — COMPLETE GUIDE

🎯 What Are Property Modifiers?

Definition:

Property modifiers in mapped types are special symbols (?, readonly) that let you add, remove, or change the optional (?) and readonly (readonly) status of properties when transforming a type.

The One-Line Summary

type NewType<T> = {
    [K in keyof T]?: T[K];         // Add optional
    readonly [K in keyof T]: T[K]; // Add readonly
    [K in keyof T]-?: T[K];        // Remove optional
    -readonly [K in keyof T]: T[K]; // Remove readonly
};

🧠 The Mental Model

┌─────────────────────────────────────────────────────────────────┐
│                    PROPERTY MODIFIERS                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  You can ADD or REMOVE two modifiers:                          │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  MODIFIER    ADD          REMOVE                         │   │
│  │  ────────    ───          ──────                         │   │
│  │  Optional    ?            -?                            │   │
│  │  Readonly    readonly     -readonly                     │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Think of it like a switch:                                    │
│  • `?` = turn ON optional                                     │
│  • `-?` = turn OFF optional                                   │
│  • `readonly` = turn ON readonly                              │
│  • `-readonly` = turn OFF readonly                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 1: The Two Modifiers

1. Optional Modifier (?)

Modifier Effect
? Makes properties optional
-? Makes properties required

2. Readonly Modifier (readonly)

Modifier Effect
readonly Makes properties readonly
-readonly Makes properties mutable

Part 2: Adding Optional (?)

Syntax

type MakeOptional<T> = {
    [K in keyof T]?: T[K];
};

Example

type User = {
    name: string;
    age: number;
    email: string;
};

type PartialUser = MakeOptional<User>;
// {
//     name?: string;
//     age?: number;
//     email?: string;
// }

Visual

┌─────────────────────────────────────────────────────────────────┐
│                    ADDING OPTIONAL (?)                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  BEFORE:                          AFTER:                        │
│  ┌───────────────────────┐       ┌───────────────────────┐     │
│  │  name: string         │       │  name?: string        │     │
│  │  age: number          │  →    │  age?: number         │     │
│  │  email: string        │       │  email?: string       │     │
│  └───────────────────────┘       └───────────────────────┘     │
│                                                                  │
│  All properties become optional.                                │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 3: Removing Optional (-?)

Syntax

type MakeRequired<T> = {
    [K in keyof T]-?: T[K];
};

Example

type PartialUser = {
    name?: string;
    age?: number;
    email?: string;
};

type RequiredUser = MakeRequired<PartialUser>;
// {
//     name: string;
//     age: number;
//     email: string;
// }

Part 6: Combining Modifiers

Optional + Readonly

type PartialReadonly<T> = {
    readonly [K in keyof T]?: T[K];
};

type User = { name: string; age: number };
type Result = PartialReadonly<User>;
// {
//     readonly name?: string;
//     readonly age?: number;
// }

Required + Mutable

type RequiredMutable<T> = {
    -readonly [K in keyof T]-?: T[K];
};

type PartialReadonlyUser = {
    readonly name?: string;
    readonly age?: number;
};

type Result = RequiredMutable<PartialReadonlyUser>;
// {
//     name: string;
//     age: number;
// }

Part 7: How Modifiers Work — Deep Dive

The + and - Prefix

┌─────────────────────────────────────────────────────────────────┐
│                    MODIFIER PREFIXES                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ?           =  +?  (add optional)      ← default, no prefix   │
│  -?          =      (remove optional)                          │
│  readonly    =  +readonly (add readonly) ← default, no prefix  │
│  -readonly   =      (remove readonly)                          │
│                                                                  │
│  The `+` is implied when you just write `?` or `readonly`.     │
│  The `-` is explicit to REMOVE the modifier.                   │
│                                                                  │
│  You can write `+?` and `+readonly` explicitly, but it's       │
│  the same as `?` and `readonly`.                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 8: Built-in Utility Types Using Modifiers

Partial<T> — Adds ?

type Partial<T> = {
    [K in keyof T]?: T[K];
};

Required<T> — Removes ?

type Required<T> = {
    [K in keyof T]-?: T[K];
};

Readonly<T> — Adds readonly

type Readonly<T> = {
    readonly [K in keyof T]: T[K];
};

Mutable<T> — Removes readonly (not built-in)

type Mutable<T> = {
    -readonly [K in keyof T]: T[K];
};

Part 9: Practical Use Cases

Use Case 1: Form State (Optional Fields)

type FormState<T> = {
    [K in keyof T]?: T[K];
};

type LoginForm = {
    email: string;
    password: string;
    rememberMe: boolean;
};

type LoginFormState = FormState<LoginForm>;
// {
//     email?: string;
//     password?: string;
//     rememberMe?: boolean;
// }

Use Case 2: Immutable Configuration

type ImmutableConfig<T> = {
    readonly [K in keyof T]: T[K];
};

type AppConfig = {
    apiUrl: string;
    timeout: number;
    retries: number;
};

type ReadonlyConfig = ImmutableConfig<AppConfig>;
// {
//     readonly apiUrl: string;
//     readonly timeout: number;
//     readonly retries: number;
// }

Use Case 3: Update Payloads (Partial)

type UpdatePayload<T> = {
    [K in keyof T]?: T[K];
};

type User = { name: string; age: number; email: string };

function updateUser(id: number, updates: UpdatePayload<User>): void {
    // ...
}

updateUser(1, { name: "Bob" }); // ✅
updateUser(1, { age: 30, email: "bob@email.com" }); // ✅
updateUser(1, {}); // ✅

Use Case 4: Making API Responses Readonly

type ApiResponse<T> = {
    readonly [K in keyof T]: T[K];
};

type UserResponse = ApiResponse<{ id: number; name: string }>;
// {
//     readonly id: number;
//     readonly name: string;
// }

const response: UserResponse = { id: 1, name: "Alice" };
// response.id = 2; // ❌ Error: readonly

Use Case 5: Combining with Key Remapping

type OptionalGetters<T> = {
    [K in keyof T as `get${Capitalize<string & K>}`]?: () => T[K];
};

type User = { name: string; age: number };
type UserGetters = OptionalGetters<User>;
// {
//     getName?: () => string;
//     getAge?: () => number;
// }

Part 10: Deep Modifiers

Deep Partial

type DeepPartial<T> = {
    [K in keyof T]?: T[K] extends object 
        ? DeepPartial<T[K]> 
        : T[K];
};

type User = {
    name: string;
    address: {
        street: string;
        city: string;
    };
};

type PartialUser = DeepPartial<User>;
// {
//     name?: string;
//     address?: {
//         street?: string;
//         city?: string;
//     };
// }

Deep Readonly

type DeepReadonly<T> = {
    readonly [K in keyof T]: T[K] extends object 
        ? DeepReadonly<T[K]> 
        : T[K];
};

type User = {
    name: string;
    address: {
        street: string;
        city: string;
    };
};

type ReadonlyUser = DeepReadonly<User>;
// {
//     readonly name: string;
//     readonly address: {
//         readonly street: string;
//         readonly city: string;
//     };
// }

Deep Required

type DeepRequired<T> = {
    [K in keyof T]-?: T[K] extends object 
        ? DeepRequired<T[K]> 
        : T[K];
};

Deep Mutable

type DeepMutable<T> = {
    -readonly [K in keyof T]: T[K] extends object 
        ? DeepMutable<T[K]> 
        : T[K];
};

Part 11: Modifier Combinations Table

Combination Syntax Effect
Optional only [K in keyof T]?: T[K] Add ?
Required only [K in keyof T]-?: T[K] Remove ?
Readonly only readonly [K in keyof T]: T[K] Add readonly
Mutable only -readonly [K in keyof T]: T[K] Remove readonly
Optional + Readonly readonly [K in keyof T]?: T[K] Add both
Required + Mutable -readonly [K in keyof T]-?: T[K] Remove both
