Part 1: What Are Nested Conditionals?

Definition:

Nested conditionals are conditional types inside other conditional types. They let you check multiple conditions in sequence, like a chain of if-else statements.

The Pattern

type Result<T> = 
    T extends Type1 ? Result1 :
    T extends Type2 ? Result2 :
    T extends Type3 ? Result3 :
    DefaultResult;

This is equivalent to:

if (T is Type1) return Result1
else if (T is Type2) return Result2
else if (T is Type3) return Result3
else return DefaultResult

Part 2: Basic Nested Conditional

Simple Example

type TypeName<T> = 
    T extends string ? "string" :
    T extends number ? "number" :
    T extends boolean ? "boolean" :
    "other";

How It Evaluates

┌─────────────────────────────────────────────────────────────────┐
│                    NESTED CONDITIONAL FLOW                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  TypeName<string>                                               │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  1. string extends string? → YES → "string"             │   │
│  │  (stops here)                                           │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  TypeName<number>                                               │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  1. number extends string? → NO                         │   │
│  │  2. number extends number? → YES → "number"             │   │
│  │  (stops here)                                           │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  TypeName<object>                                               │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  1. object extends string? → NO                         │   │
│  │  2. object extends number? → NO                         │   │
│  │  3. object extends boolean? → NO                        │   │
│  │  4. Default → "other"                                   │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Testing

type A = TypeName<string>;  // "string"
type B = TypeName<number>;  // "number"
type C = TypeName<boolean>; // "boolean"
type D = TypeName<object>;  // "other"

Part 3: Key Removal in Mapped Types

What Is Key Removal?

Definition:

Key removal is the technique of using never in the as clause of a mapped type to filter out specific keys from the resulting type.

The Pattern

type RemoveKeys<T> = {
    [K in keyof T as Condition ? never : K]: T[K];
};

When a key maps to never, it is removed from the type.

Part 4: How Key Removal Works

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    KEY REMOVAL PROCESS                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: Iterate over keys                                     │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  [K in keyof T]                                         │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 2: Check condition for each key                          │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  K extends SomeCondition ? never : K                    │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 3: If condition is true, key becomes never               │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  never → key is REMOVED from the type                   │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  Step 4: If condition is false, key stays                     │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  K → key is KEPT                                        │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 5: Simple Key Removal Examples

Example 1: Remove Keys Starting with Underscore

type RemovePrivate<T> = {
    [K in keyof T as K extends `_${string}` ? never : K]: T[K];
};

type Data = {
    _internal: string;
    _private: number;
    name: string;
    age: number;
};

type PublicData = RemovePrivate<Data>;
// {
//     name: string;
//     age: number;
// }

Example 2: Remove Function Properties

type RemoveFunctions<T> = {
    [K in keyof T as T[K] extends Function ? never : K]: T[K];
};

type User = {
    name: string;
    age: number;
    greet: () => void;
    walk: () => void;
};

type UserData = RemoveFunctions<User>;
// {
//     name: string;
//     age: number;
// }

Example 3: Remove Optional Properties

type RemoveOptional<T> = {
    [K in keyof T as {} extends Pick<T, K> ? never : K]: T[K];
};

type User = {
    name: string;
    age?: number;
    email: string;
    phone?: string;
};

type RequiredUser = RemoveOptional<User>;
// {
//     name: string;
//     email: string;
// }

Part 6: Nested Conditionals in Key Removal

The Pattern

type SmartRemove<T> = {
    [K in keyof T as 
        K extends `_${string}` ? never :
        T[K] extends Function ? never :
        T[K] extends null | undefined ? never :
        K
    ]: T[K];
};

How It Works

┌─────────────────────────────────────────────────────────────────┐
│                    NESTED KEY REMOVAL                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  For each key K:                                                │
│                                                                  │
│  1. Does K start with "_"?                                     │
│     YES → never (remove)                                       │
│     NO → go to 2                                               │
│                                                                  │
│  2. Does T[K] extend Function?                                 │
│     YES → never (remove)                                       │
│     NO → go to 3                                               │
│                                                                  │
│  3. Does T[K] extend null | undefined?                         │
│     YES → never (remove)                                       │
│     NO → keep K                                                │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Example

type Data = {
    _internal: string;
    name: string;
    age: number;
    callback: () => void;
    optional: string | null;
    active: boolean;
};

type CleanData = SmartRemove<Data>;
// {
//     name: string;
//     age: number;
//     active: boolean;
// }

Part 7: Real-World Examples

Example 1: Removing Sensitive Data

type RemoveSensitive<T> = {
    [K in keyof T as 
        K extends "password" | "token" | "secret" | "apiKey" ? never :
        K
    ]: T[K];
};

type User = {
    id: number;
    name: string;
    password: string;
    token: string;
    email: string;
};

type SafeUser = RemoveSensitive<User>;
// {
//     id: number;
//     name: string;
//     email: string;
// }

Example 2: Filter by Value Type

type FilterByType<T, AllowedType> = {
    [K in keyof T as T[K] extends AllowedType ? K : never]: T[K];
};

type User = {
    name: string;
    age: number;
    email: string;
    isActive: boolean;
};

type OnlyStrings = FilterByType<User, string>;
// {
//     name: string;
//     email: string;
// }

type OnlyNumbers = FilterByType<User, number>;
// {
//     age: number;
// }

Example 3: Clean Data for API Response

type CleanForApi<T> = {
    [K in keyof T as 
        K extends `_${string}` ? never :
        T[K] extends Function ? never :
        T[K] extends undefined ? never :
        K
    ]: T[K];
};

type InternalData = {
    _id: string;
    name: string;
    email: string;
    _createdAt: Date;
    validate: () => boolean;
    age?: number;
};

type ApiData = CleanForApi<InternalData>;
// {
//     name: string;
//     email: string;
//     age?: number;
// }

Example 4: Remove Nullable Properties

type RemoveNullable<T> = {
    [K in keyof T as null extends T[K] ? never : K]: T[K];
};

type User = {
    name: string;
    age: number | null;
    email: string;
    phone: string | null;
};

type NonNullableUser = RemoveNullable<User>;
// {
//     name: string;
//     email: string;
// }

Part 8: Combining Nested Conditionals with Key Removal

Pattern: Advanced Filtering

type SmartFilter<T> = {
    [K in keyof T as 
        K extends `_${string}` ? never :
        T[K] extends string ? K :
        T[K] extends number ? K :
        T[K] extends boolean ? K :
        never
    ]: T[K];
};

type Data = {
    _internal: string;
    name: string;
    age: number;
    isActive: boolean;
    createdAt: Date;
    callback: () => void;
};

type SimpleData = SmartFilter<Data>;
// {
//     name: string;
//     age: number;
//     isActive: boolean;
// }

Pattern: Remove by Multiple Conditions

type RemoveUnwanted<T> = {
    [K in keyof T as 
        K extends `_${string}` ? never :
        K extends "password" | "token" ? never :
        T[K] extends Function ? never :
        T[K] extends null | undefined ? never :
        K
    ]: T[K];
};
