Type-Level Foundations

THE FUNDAMENTAL UNIT OF TYPE-LEVEL PROGRAMMING

🎯 The Short Answer

The fundamental unit of type-level programming is the type itself — specifically, the ability to define, transform, and constrain types using generic type parameters.

But that's too vague. Let's break it down precisely.

🔬 The Real Fundamental Unit: The Conditional Type

If you had to pick one construct that makes type-level programming possible, it is: 

T extends U ? X : Y

This is the conditional type. It is the if-statement of the type world.

Why This Is The Fundamental Unit

Feature How It's Built
If/else T extends U ? X : Y
Loops Recursion using conditional types
Pattern matching T extends { x: infer X } ? X : never
Booleans true / false literal types
Equality A extends B ? (B extends A ? true : false) : false
Logic (AND/OR/NOT) Built from conditional types

Everything in type-level programming is built on top of the conditional type.

🧩 Building Blocks From The Fundamentals

1. Booleans (from Conditional Types)

type True = true;
type False = false;

// NOT
type Not<B extends boolean> = B extends true ? false : true;

// AND
type And<A extends boolean, B extends boolean> = 
    A extends true ? (B extends true ? true : false) : false;

// OR
type Or<A extends boolean, B extends boolean> = 
    A extends true ? true : (B extends true ? true : false);

2. Equality (from Conditional Types)

type Equal<A, B> = 
    A extends B 
        ? (B extends A ? true : false) 
        : false;

type Test1 = Equal<"hello", "hello">; // true
type Test2 = Equal<"hello", "world">; // false

3. Numbers (from Tuples)

// Build a tuple of length N
type BuildTuple<N extends number, T extends any[] = []> = 
    T['length'] extends N 
        ? T 
        : BuildTuple<N, [...T, any]>;

// Addition
type Add<A extends number, B extends number> = 
    [...BuildTuple<A>, ...BuildTuple<B>]['length'];

type Sum = Add<3, 4>; // 7

4. Loops (from Recursion)

// Map over a tuple
type MapTuple<T extends any[], F extends (x: any) => any> = 
    T extends [infer Head, ...infer Tail]
        ? [F extends (x: Head) => infer R ? R : never, ...MapTuple<Tail, F>]
        : [];

type Double = <T extends number>(x: T) => `${T}`;
type Result = MapTuple<[1, 2, 3], Double>; // ["1", "2", "3"]

🧠 The Core Insight

Type-level programming is programming with extends.

Everything you write at the type level is fundamentally:

  • Declaring a type parameter (<T>)
  • Checking if it extends something (T extends U)
  • Producing a result based on that check (? X : Y)
  • Repeating via recursion

📊 Comparison: Value Level vs Type Level

Value Level Type Level Fundamental Unit
let x = 5 type X = 5 Declaration
if (x) { } T extends U ? X : Y Conditional
for (const k in obj) { [K in keyof T]: ... } Mapped type
function f() { } type F<T> = ... Generic
return x : X Return type
const { a } = obj T extends { a: infer A } ? A : never infer

🎯 The One-Sentence Answer

The fundamental unit of type-level programming is the conditional type T extends U ? X : Y, because it provides the branching, pattern-matching, and recursion needed to compute anything at the type level.
