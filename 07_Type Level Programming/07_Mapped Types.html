WHAT ARE MAPPED TYPES?

Definition:

A mapped type is a type that transforms an existing type by iterating over its keys and producing a new type based on those keys. It's like a loop at the type level.

The One-Line Summary

type NewType<T> = {
    [K in keyof T]: /* transformed type */
};
  • K = each key of T
  • keyof T = the union of all keys of T
  • The result is a new type with the same or modified keys

🧠 The Mental Model

┌─────────────────────────────────────────────────────────────────┐
│                    MAPPED TYPES                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  VALUE LEVEL (Runtime):           TYPE LEVEL (Compile-Time):   │
│  ─────────────────────           ────────────────────────       │
│                                                                  │
│  const result = {};              type Result<T> = {            │
│  for (const key in obj) {           [K in keyof T]: T[K]      │
│      result[key] = obj[key];      };                           │
│  }                                                             │
│                                                                  │
│  Loop over keys.                 Map over keys.               │
│  Build a new object.             Build a new type.             │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 1: Basic Syntax

Basic Syntax

type T = {
  [K in Keys]: ValueType;
};
  • K → placeholder for each key
  • Keys → union of keys
  • ValueType → type of each generated property

Basic Example

type Keys = "id" | "name";

type User = {
  [K in Keys]: string;
};

Result:

{
  id: string;
  name: string;
}

OR

Part 1: Basic Syntax

type MappedType<T> = {
    [K in keyof T]: T[K];
};

Syntax Breakdown

type MappedType<T> = {
    [K in keyof T]: T[K];
//   ↑    ↑         ↑
//   |    |         |
//   |    |         Value type
//   |    Iteration source
//   Key variable
};

Simple Example

type User = {
    name: string;
    age: number;
    email: string;
};

// Clone the type (identity mapped type)
type Clone<T> = {
    [K in keyof T]: T[K];
};

type ClonedUser = Clone<User>;
// ClonedUser = { name: string; age: number; email: string }

Part 3: Modifying Properties

1. Making Properties Optional (?)

type MyPartial<T> = {
    [K in keyof T]?: T[K];
};

type User = { name: string; age: number };

type PartialUser = MyPartial<User>;
// { name?: string; age?: number }

2. Making Properties Readonly (readonly)

type MyReadonly<T> = {
    readonly [K in keyof T]: T[K];
};

type User = { name: string; age: number };

type ReadonlyUser = MyReadonly<User>;
// { readonly name: string; readonly age: number }

3. Removing Modifiers (-?, -readonly)

// Remove optional
type MyRequired<T> = {
    [K in keyof T]-?: T[K];
};

type PartialUser = { name?: string; age?: number };
type RequiredUser = MyRequired<PartialUser>;
// { name: string; age: number }

// Remove readonly
type Mutable<T> = {
    -readonly [K in keyof T]: T[K];
};

type ReadonlyUser = { readonly name: string; readonly age: number };
type MutableUser = Mutable<ReadonlyUser>;
// { name: string; age: number }

Modifier Summary

Modifier Effect
? Add optional
-? Remove optional
readonly Add readonly
-readonly Remove readonly

Part 4: Filtering Keys

Using Conditional Types in Mapped Types

// Only include string keys
type StringKeys<T> = {
    [K in keyof T]: T[K] extends string ? K : never;
}[keyof T];

type User = {
    name: string;
    age: number;
    email: string;
};

type UserStringKeys = StringKeys<User>;
// "name" | "email"

Explanation :

[K in keyof T] creates a mapped object type. It checks each property and assigns that property’s key if its value is a string, or never otherwise.

For User, the mapped type is effectively:

{
  name: "name";
  age: never;
  email: "email";
}

That object still has all the original keys; never is just the value of the age property.

The trailing [keyof T] is an indexed access type. It says: “Take the values of this mapped type for every key in T.” So it produces:

"name" | never | "email"

Since never contributes no possibilities to a union, that simplifies to:

"name" | "email"

Part 6: Built-in Mapped Types

TypeScript's Built-in Mapped Types

Built-in Type What It Does
Partial<T> Makes all properties optional
Required<T> Makes all properties required
Readonly<T> Makes all properties readonly
Pick<T, K> Picks specific keys
Record<K, T> Creates object with keys K
Exclude<T, U> Removes types from union
Extract<T, U> Extracts types from union

Part 7: Practical Use Cases

Use Case 1: Type-Safe Form State

type FormState<T> = {
    [K in keyof T]: {
        value: T[K];
        error: string | null;
        touched: boolean;
    };
};

type LoginForm = {
    email: string;
    password: string;
};

type LoginFormState = FormState<LoginForm>;
// {
//     email: { value: string; error: string | null; touched: boolean };
//     password: { value: string; error: string | null; touched: boolean };
// }

Use Case 2: API Response Wrapping

type ApiResponse<T> = {
    [K in keyof T]: {
        data: T[K];
        status: number;
        timestamp: string;
    };
};

type UserResponse = ApiResponse<{ user: { name: string; age: number } }>;
// {
//     user: {
//         data: { name: string; age: number };
//         status: number;
//         timestamp: string;
//     };
// }
