KEY REMAPPING IN MAPPED TYPES — COMPLETE GUIDE

🎯 What is Key Remapping?

Definition:

Key remapping is a feature in mapped types that lets you rename, transform, or filter keys using the as clause. Instead of keeping the original property names, you can produce new key names based on the original keys.

The One-Line Summary

type NewType<T> = {
    [K in keyof T as NewKeyName]: T[K];
};
//                  ↑
//                  |
//           Key remapping with 'as'

type RemappedType<T> = {
    [K in keyof T as NewKeyExpression]: T[K];

//   |           |                                 |
//   |           Key remapping clause              Value type

Part 3: Simple Examples

Example 1: Adding Prefix

type WithPrefix<T> = {
    [K in keyof T as `prefix_${string & K}`]: T[K];
};

type User = { name: string; age: number };
type PrefixedUser = WithPrefix<User>;
// { prefix_name: string; prefix_age: number }

why string here : `prefix_${string & K}`

a template-literal `` type like `get${K}` still requires K to be a string, number, bigint, boolean, null, or undefined. But keyof T can include symbol, and symbols can’t be interpolated into template-literal types.

string & K is a type intersection: it keeps only the part of K that is also a string.
In a mapped type, K comes from keyof T. TypeScript treats that as potentially including symbol, and template literals can’t interpolate symbols. The intersection narrows the key type to strings, making it valid in `get${...}`:

type ProWithPrefix<T> = {
    [K in keyof T as `get${string & K}`]: () => T[K]
}

For a key K:

  • If K is "name", then string & "name" is "name", so the remapped key is "getname".
  • If K is symbol, then string & symbol is never, so that key is excluded from the mapped result.

Example 2: Adding Suffix

type WithSuffix<T> = {
    [K in keyof T as `${string & K}_changed`]: T[K];
};

type User = { name: string; age: number };
type SuffixedUser = WithSuffix<User>;
// { name_changed: string; age_changed: number }

Example 3: Capitalizing Keys

type Capitalized<T> = {
    [K in keyof T as Capitalize<string & K>]: T[K];
};

type User = { name: string; age: number };
type CapitalizedUser = Capitalized<User>;
// { Name: string; Age: number }

Part 4: Filtering Keys

Using never to Remove Keys

type OnlyStrings<T> = {
    [K in keyof T as T[K] extends string ? K : never]: T[K];
};

type User = {
    name: string;
    age: number;
    email: string;
    isActive: boolean;
};

type UserStrings = OnlyStrings<User>;
// { name: string; email: string }
// (age and isActive are removed)

How Filtering Works

┌─────────────────────────────────────────────────────────────────┐
│                    FILTERING WITH never                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  [K in keyof T as T[K] extends string ? K : never]             │
│                                                                  │
│  K = "name"     → string extends string? → "name" (keep)       │
│  K = "age"      → number extends string? → never (remove)      │
│  K = "email"    → string extends string? → "email" (keep)      │
│  K = "isActive" → boolean extends string? → never (remove)     │
│                                                                  │
│  Result: { name: string; email: string }                       │
│                                                                  │
│  When a key maps to `never`, it's REMOVED from the type.       │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 5: Common Patterns

Pattern 1: Getters

type Getters<T> = {
    [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type User = { name: string; age: number };
type UserGetters = Getters<User>;
// {
//     getName: () => string;
//     getAge: () => number;
// }

Pattern 2: Setters

type Setters<T> = {
    [K in keyof T as `set${Capitalize<string & K>}`]: (value: T[K]) => void;
};

type User = { name: string; age: number };
type UserSetters = Setters<User>;
// {
//     setName: (value: string) => void;
//     setAge: (value: number) => void;
// }

Part 7: Real-World Use Cases

Use Case 1: API Response Transformation

type ApiResponseToData<T> = {
    [K in keyof T as `data_${string & K}`]: T[K];
};

type ApiResponse = {
    user: { name: string };
    posts: { title: string }[];
};

type Transformed = ApiResponseToData<ApiResponse>;
// {
//     data_user: { name: string };
//     data_posts: { title: string }[];
// }

Use Case 2: Database Column Mapping

type SnakeCase<S extends string> = S extends `${infer T}${infer U}`
    ? U extends Uncapitalize<U>
    ? `${Lowercase<T>}${CamelToSnakeCase<U>}`
    : `${Lowercase<T>}_${CamelToSnakeCase<Uncapitalize<U>>}`
    : S;    

type ToSnakeCase<T> = {
    [K in keyof T as K extends string 
        ? SnakeCase<K> 
        : K
    ]: T[K];
};

type User = { firstName: string; lastName: string };
type DbUser = ToSnakeCase<User>;
// { first_name: string; last_name: string }

Summary Table
