Type-Level Arithmetic Operations in TypeScript

🎯 What is Type-Level Arithmetic?

Definition:

Type-level arithmetic is performing mathematical operations (addition, subtraction, multiplication, etc.) using only TypeScript's type system — no runtime code, no values, just types.

This is possible because TypeScript's type system is Turing complete.

🧠 The Core Idea

┌─────────────────────────────────────────────────────────────────┐
│                    TYPE-LEVEL ARITHMETIC                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  VALUE LEVEL (Runtime):         TYPE LEVEL (Compile-Time):     │
│  ─────────────────────         ────────────────────────         │
│                                                                  │
│  const sum = 3 + 4;             type Sum = Add<3, 4>;          │
│  // sum = 7                     // Sum = 7                     │
│                                                                  │
│  You compute at runtime.        You compute at compile time.   │
│                                                                  │
│  🔑 KEY INSIGHT:                                                │
│  We use TUPLE LENGTHS to represent numbers!                    │
│  [any, any, any]['length'] = 3                                 │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Part 1: The Foundation — Tuples as Numbers

The Secret

TypeScript can't do math directly on number types. But it can count tuple lengths.

type Zero = [];
type One = [any];
type Two = [any, any];
type Three = [any, any, any];

// Get the number from a tuple
type Length<T extends any[]> = T['length'];

type A = Length<Three>; // 3

Explanation

T['length'] is TypeScript’s indexed access type. It means: “Look up the type of the length property on type T.”

Here, T is constrained to be an array or tuple:

type Length<T extends any[]> = T['length'];

When T is Three, TypeScript substitutes it in:

type Three = [any, any, any];

type A = Length<Three>;
// equivalent to:
type A = Three['length'];

A tuple has a fixed number of elements, so its length property has the literal type 3. Therefore, A is 3.

Compare that to a regular array, whose length can change:

type ArrayLength = string[]['length']; // number

So T['length'] doesn’t count elements at runtime; it asks TypeScript for the type of that property.

Building Tuples of Any Length (Recursion)

type BuildTuple<N extends number, T extends any[] = []> = 
    T['length'] extends N 
        ? T 
        : BuildTuple<N, [...T, any]>;

type A = BuildTuple<0>; // []
type B = BuildTuple<1>; // [any]
type C = BuildTuple<3>; // [any, any, any]
type D = BuildTuple<5>; // [any, any, any, any, any]

Visual

│                    TUPLES AS NUMBERS                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Number 3 is represented as: [any, any, any]                   │
│                                                                  │
│  [any, any, any]['length'] = 3                                 │
│                                                                  │
│  Why? Because TypeScript CAN count tuple elements.             │
│  But TypeScript CANNOT do 3 + 4 directly.                      │
│                                                                  │

│  3 → [any, any, any]                                           │

Part 2: Addition

How It Works

Addition combines two tuples and counts the result.

type Add<A extends number, B extends number> = 
    [...BuildTuple<A>, ...BuildTuple<B>]['length'];

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    ADDITION STEPS                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Add<3, 4>                                                      │
│                                                                  │
│  Step 1: BuildTuple<3> = [any, any, any]                       │
│  Step 2: BuildTuple<4> = [any, any, any, any]                  │
│  Step 3: Combine = [any, any, any, any, any, any, any]         │
│  Step 4: Count length = 7                                      │
│                                                                  │
│  Result: 7                                                      │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Examples

type A = Add<0, 0>;   // 0
type B = Add<1, 2>;   // 3
type C = Add<5, 5>;   // 10
type D = Add<10, 20>; // 30

Part 3: Subtraction

How It Works

Subtraction removes elements from a tuple.

type Subtract<A extends number, B extends number> = 
    BuildTuple<A> extends [...BuildTuple<B>, ...infer Rest]
        ? Rest['length']
        : never;

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    SUBTRACTION STEPS                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Subtract<5, 2>                                                 │
│                                                                  │
│  Step 1: BuildTuple<5> = [any, any, any, any, any]             │
│  Step 2: BuildTuple<2> = [any, any]                            │
│  Step 3: Match: [any, any, ...Rest]                            │
│          Rest = [any, any, any]                                │
│  Step 4: Count Rest = 3                                        │
│                                                                  │
│  Result: 3                                                      │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Examples

type A = Subtract<5, 2>;  // 3
type B = Subtract<10, 3>; // 7
type C = Subtract<3, 3>;  // 0
type D = Subtract<2, 5>;  // never (can't subtract bigger from smaller)

Part 4: Multiplication

How It Works

Multiplication is repeated addition.

type Multiply<A extends number, B extends number, Acc extends any[] = []> = 
    B extends 0 
        ? Acc['length']
        : Multiply<A, Subtract<B, 1>, [...Acc, ...BuildTuple<A>]>;

Step by Step

┌─────────────────────────────────────────────────────────────────┐
│                    MULTIPLICATION STEPS                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Multiply<3, 4>                                                 │
│  = 3 + 3 + 3 + 3 = 12                                          │
│                                                                  │
│  Step 1: Acc = [], B = 4 → add [any, any, any]                 │
│  Step 2: Acc = [3 items], B = 3 → add [any, any, any]          │
│  Step 3: Acc = [6 items], B = 2 → add [any, any, any]          │
│  Step 4: Acc = [9 items], B = 1 → add [any, any, any]          │
│  Step 5: Acc = [12 items], B = 0 → BASE CASE                   │
│  Step 6: Count = 12                                            │
│                                                                  │
│  Result: 12                                                     │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Examples

type A = Multiply<2, 3>; // 6
type B = Multiply<4, 5>; // 20
type C = Multiply<0, 5>; // 0

Part 5: Division

How It Works

Division counts how many times B fits into A.

type Divide<A extends number, B extends number, Acc extends any[] = []> = 
    B extends 0 
        ? never  // Can't divide by zero
        : A extends 0 
            ? Acc['length']
            : A extends [...BuildTuple<B>, ...infer Rest]
                ? Divide<Rest['length'], B, [...Acc, any]>
                : Acc['length'];

Examples

type A = Divide<10, 2>; // 5
type B = Divide<15, 3>; // 5
type C = Divide<7, 2>;  // 3 (integer division)
type D = Divide<5, 0>;  // never
