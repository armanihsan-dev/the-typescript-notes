📚 Phase 1: Foundations (Weeks 1-2)

Goals

  • Understand the fundamental building blocks
  • Write simple conditional types
  • Work with unions and intersections

Topics

Topic What to Learn Practice
Generic Parameters <T>, <T, U>, defaults, constraints Write identity, pair, wrap
Conditional Types T extends U ? X : Y Write IsString, IsNumber
Union Types A | B, distribution Write ToArray
Intersection Types A & B, merging Write Merge
Type Aliases type, interface Create reusable types

Key Exercises

// 1. Write a type that checks if a type is a string
type IsString<T> = T extends string ? true : false;

// 2. Write a type that returns the first element of a tuple
type First<T extends any[]> = T extends [infer Head, ...any[]] ? Head : never;

// 3. Write a type that makes all properties optional
type MyPartial<T> = { [K in keyof T]?: T[K] };

// 4. Write a type that extracts string keys from an object
type StringKeys<T> = {
    [K in keyof T]: T[K] extends string ? K : never
}[keyof T];

📚 Phase 2: Core Mechanisms (Weeks 3-4)

Goals

  • Master mapped types
  • Use keyof, typeof, indexed access
  • Create template literal types

Topics

Topic What to Learn Practice
Mapped Types { [K in keyof T]: ... } Write Readonly, Required
keyof Getting keys of a type Write KeysOf
typeof Getting type from value Write TypeOf
Indexed Access T["key"], T[number] Write ValueOf
Template Literals `${T}`, ${string} Write EventName, Route
Modifiers +?, -?, +readonly, -readonly Write Mutable

Key Exercises

// 1. Write a type that removes readonly modifiers
type Mutable<T> = { -readonly [K in keyof T]: T[K] };

// 2. Write a type that gets all values of an object
type ValueOf<T> = T[keyof T];

// 3. Write a type that adds "on" prefix to event names
type EventName<T extends string> = `on${Capitalize<T>}`;

// 4. Write a type that removes optional modifiers
type Required<T> = { [K in keyof T]-?: T[K] };

📚 Phase 3: Inference & Pattern Matching (Weeks 5-6)

Goals

  • Master the infer keyword
  • Write recursive conditional types
  • Understand distribution

Topics

Topic What to Learn Practice
infer Pattern matching in types Write ReturnType, Parameters
Recursion Recursive types Write Flatten, DeepReadonly
Distribution How unions distribute Write Exclude, Extract
Type Guards T extends U as guard Write IsArray, IsFunction
Naked Type Parameters When distribution happens Understand [T] extends [U]

Key Exercises

// 1. Write a type that gets the return type of a function
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

// 2. Write a type that flattens an array
type Flatten<T> = T extends (infer U)[] ? U : T;

// 3. Write a type that deep-reads all properties
type DeepReadonly<T> = {
    readonly [K in keyof T]: T[K] extends object 
        ? DeepReadonly<T[K]> 
        : T[K];
};

// 4. Write a type that removes null and undefined
type NonNullable<T> = T extends null | undefined ? never : T;

📚 Phase 4: Advanced Constructs (Weeks 7-8)

Goals

  • Master variadic tuple types
  • Build type-level arithmetic
  • Create type-level data structures

Topics

Topic What to Learn Practice
Variadic Tuples [...T, ...U] Write Concat, Push
Tuple Manipulation [infer H, ...infer T] Write Head, Tail
Type Arithmetic Build numbers from tuples Write Add, Subtract
Type-Level Strings Parse strings at type level Write Split, Join
Type-Level Objects Object manipulation Write Merge, DeepMerge

Key Exercises

// 1. Write a type that concatenates two tuples
type Concat<T extends any[], U extends any[]> = [...T, ...U];

// 2. Write a type that gets the last element of a tuple
type Last<T extends any[]> = T extends [...any[], infer L] ? L : never;

// 3. Write a type that splits a string by a delimiter
type Split<S extends string, D extends string> = 
    S extends `${infer Head}${D}${infer Tail}`
        ? [Head, ...Split<Tail, D>]
        : [S];

// 4. Write a type that joins an array of strings
type Join<T extends string[], D extends string> = 
    T extends [infer Head, ...infer Tail]
        ? Head extends string
            ? Tail extends string[]
                ? `${Head}${D}${Join<Tail, D>}`
                : Head
            : never
        : "";

Key Projects

// 1. Type-Safe Route Parser
type ExtractParams<T extends string> = 
    T extends `${string}:${infer Param}/${infer Rest}`
        ? Param | ExtractParams<`/${Rest}`>
        : T extends `${string}:${infer Param}`
            ? Param
            : never;

// 2. Type-Safe API Client
interface ApiSchema {
    "/users": { GET: User[]; POST: User };
    "/users/:id": { GET: User; DELETE: void };
}

// 3. Type-Level Email Validator
type Email = `${string}@${string}.${string}`;

// 4. Type-Level State Machine
type State = "idle" | "loading" | "success" | "error";
type Transitions = {
    idle: "loading";
    loading: "success" | "error";
    success: "idle";
    error: "idle";
};

Key Exercises

// 1. Type-Level Sort
type Sort<T extends number[]> = 
    T extends [infer A extends number, infer B extends number, ...infer Rest]
        ? A extends B
            ? [A, ...Sort<[B, ...Rest]>]
            : [B, ...Sort<[A, ...Rest]>]
        : T;

// 2. Type-Level Find
type Find<T extends any[], Predicate> = 
    T extends [infer Head, ...infer Tail]
        ? Head extends Predicate
            ? Head
            : Find<Tail, Predicate>
        : never;
