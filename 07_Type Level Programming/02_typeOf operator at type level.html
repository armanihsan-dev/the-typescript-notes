Part 1: What is typeof at Type Level?

Definition

typeof at the type level takes a value (a variable, function, object, class) and extracts its type as a TypeScript type.

The Syntax

type TypeName = typeof value;
  • value is a runtime value (variable, function, object)
  • TypeName becomes the type of that value

The Core Idea

// You have a value
const user = { name: "Alice", age: 25 };

// You want its type
type User = typeof user;
// User = { name: string; age: number }

// Now you can use it as a type
const anotherUser: User = { name: "Bob", age: 30 };

Part 2: How It Works — Simple Examples

Example 1: Primitive Value

const num = 42;
type NumType = typeof num;
// NumType = 42 (literal type!)

const str = "hello";
type StrType = typeof str;
// StrType = "hello"

const bool = true;
type BoolType = typeof bool;
// BoolType = true

Example 2: Object Value

const user = {
    name: "Alice",
    age: 25,
    email: "alice@email.com"
};

type UserType = typeof user;
// UserType = {
//     name: string;
//     age: number;
//     email: string;
// }

Example 3: Array Value

const numbers = [1, 2, 3, 4, 5];
type NumbersType = typeof numbers;
// NumbersType = number[]

Example 4: Function Value

function greet(name: string): string {
    return `Hello ${name}`;
}

type GreetType = typeof greet;
// GreetType = (name: string) => string

Example 5: Class Value

class Person {
    name: string;
    constructor(name: string) {
        this.name = name;
    }
    greet(): string {
        return `Hello, I'm ${this.name}`;
    }
}

type PersonType = typeof Person;
// PersonType = typeof Person (the constructor function type)
// This is the CLASS itself, not an instance!

typeof Person refers to the class constructor, not an instance:

type PersonType = typeof Person;
// typeof Person = new (name: string) => Person

so this is incorrect
let p1: PersonType = new Person("Arman");

PersonType expects the constructor itself, which has a prototype property. new Person(...) returns an instance and does not have that constructor shape.

Use Person for an instance:

let p1: Person = new Person("Arman");

type PersonInstance = InstanceType<typeof Person>;

let p1: PersonInstance = new Person("Arman");

Use typeof Person only when storing the class constructor:

const PersonConstructor: typeof Person = Person;
const p1 = new PersonConstructor("Arman");

REAL USE CASE OF

type PersonType = typeof Person;

Its use case is when you want to store, pass, or accept the class itself:

function createPerson(PersonClass: typeof Person, name: string): Person {
    return new PersonClass(name);
}

const person = createPerson(Person, "Arman");
console.log(person.greet());

It is also useful for constructor variables:

const PersonConstructor: PersonType = Person;

const person = new PersonConstructor("Arman");

the Difference is

type PersonInstance = Person;       // an object created by the class
type PersonConstructor = typeof Person; // the class/constructor itself

InShort

const instance: Person = new Person("Arman");
const constructor: typeof Person = Person;

Part 3: Why typeof is Useful

3.1 Avoid Duplicating Types

// ❌ Without typeof: You duplicate the type
const config = {
    apiUrl: "https://api.com",
    timeout: 5000,
    retries: 3
};

interface Config {
    apiUrl: string;
    timeout: number;
    retries: number;
}

// ✅ With typeof: Extract the type
const config = {
    apiUrl: "https://api.com",
    timeout: 5000,
    retries: 3
};

type Config = typeof config;
// No duplication!

3.2 Type-Safe Constants

// ✅ Define values first, then extract types
const ROUTES = {
    home: "/",
    about: "/about",
    contact: "/contact"
} as const;

type Route = typeof ROUTES[keyof typeof ROUTES];
// Route = "/" | "/about" | "/contact"

// Now you can use it for type safety
function navigate(route: Route): void {
    // ...
}

navigate("/");        // ✅ Works
navigate("/about");   // ✅ Works
navigate("/unknown"); // ❌ Error

3.3 Extract Types from Libraries

// ✅ Use typeof to extract types from third-party libraries
import express from "express";

type Request = typeof express.request;
type Response = typeof express.response;

3.4 Function Return Types

// ✅ Extract the return type of a function
function createUser(name: string, age: number) {
    return {
        id: Math.random().toString(36),
        name,
        age,
        createdAt: new Date()
    };
}

type User = ReturnType<typeof createUser>;
// User = {
//     id: string;
//     name: string;
//     age: number;
//     createdAt: Date;
// }

Part 4: typeof Combined with Other Operators

4.1 typeof with keyof

const user = {
    name: "Alice",
    age: 25,
    email: "alice@email.com"
};

type UserKeys = keyof typeof user;
// UserKeys = "name" | "age" | "email"

// Usage:
function getValue(key: UserKeys): any {
    return user[key];
}

getValue("name");  // ✅ Works
getValue("email"); // ✅ Works
getValue("phone"); // ❌ Error

4.2 typeof with Indexed Access

const config = {
    apiUrl: "https://api.com",
    timeout: 5000,
    retries: 3
};

type ApiUrl = (typeof config)["apiUrl"];
// ApiUrl = string

type Timeout = (typeof config)["timeout"];
// Timeout = number

4.3 typeof with keyof and Indexed Access

const config = {
    apiUrl: "https://api.com",
    timeout: 5000,
    retries: 3
};

type ConfigValue = (typeof config)[keyof typeof config];
// ConfigValue = string | number

4.4 typeof with Arrays

const colors = ["red", "green", "blue"] as const;

type Color = typeof colors[number];
// Color = "red" | "green" | "blue"

// Without `as const`:
const colors2 = ["red", "green", "blue"];
type Color2 = typeof colors2[number];
// Color2 = string

Part 5: typeof in Different Contexts

5.1 In Type Aliases

const user = { name: "Alice", age: 25 };

type User = typeof user;
// User = { name: string; age: number }

5.2 In Function Parameters

const defaultConfig = {
    timeout: 5000,
    retries: 3
};

function setup(config: typeof defaultConfig): void {
    // config must match the shape of defaultConfig
}

setup({ timeout: 10000, retries: 5 }); // ✅ Works
setup({ timeout: 10000 }); // ❌ Error: missing retries

The ReturnType<Type> Utility Type

If you need to extract or reuse the return type of an existing function type, TypeScript provides the built-in ReturnType Utility Type.Because ReturnType expects a type as its parameter, you must use it in combination with typeof if you are targeting a real JavaScript function.

function createUser() {
  return { id: 1, name: "John Doe", active: true };
}

// Extract the type from the function above
type User = ReturnType<typeof createUser>;

typeof vs ReturnType vs InstanceType

Operator What It Does Example
typeof value Gets the type of a value typeof user → { name: string }
ReturnType<T> Gets the return type of a function ReturnType<typeof fn> → return type
InstanceType<T> Gets the instance type of a class InstanceType<typeof Person> → Person
